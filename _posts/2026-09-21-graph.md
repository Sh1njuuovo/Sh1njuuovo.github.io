## 一句话概括

图论这一组四道题覆盖三种不同的东西。200 和 994 是网格上的遍历，一个数连通块的数量，一个数扩散的层数。207 是显式建好的有向图，判断有没有环。208 是树结构的设计题。它们的共同点是都要控制「哪些节点已经处理过」。

## 怎么选工具

- 网格上问有多少片连通的区域 → 深搜或者广搜，一边走一边数
- 网格上问扩散完要几轮 → 多源广搜，外层按层计数
- 有依赖关系，问能不能全部做完 → 拓扑排序，或者深搜判环
- 一堆字符串里按前缀查 → Trie

## Python 基础

### 图在 Python 里怎么存

邻接表最常用，`graph[i]` 里放节点 i 的所有邻居。

```python
n = 4
edges = [[0, 1], [1, 2], [2, 3]]

graph = [[] for _ in range(n)]
for u, v in edges:
    graph[u].append(v)
    graph[v].append(u)      # 有向图删掉这一行
```

邻接矩阵查一条边很快，但空间是 O(n²)，只有稠密图和需要快速判边时才用。

```python
graph = [[0] * n for _ in range(n)]
for u, v in edges:
    graph[u][v] = 1
    graph[v][u] = 1
```

### 网格也是一种图

每个格子是一个节点，上下左右相邻的格子之间有边。这种图不用建表，邻居位置直接算出来。

```python
dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]
m, n = len(grid), len(grid[0])

if 0 <= nx < m and 0 <= ny < n:     # 连着的比较，等价于 nx >= 0 and nx < m
    ...
```

### 四种遍历模板

深搜，递归版。

```python
def dfs(node):
    visited.add(node)
    for nxt in graph[node]:
        if nxt not in visited:
            dfs(nxt)
```

深搜，栈版。数据量大时用它，避免递归深度超限。

```python
stack = [start]
visited = {start}
while stack:
    node = stack.pop()
    for nxt in graph[node]:
        if nxt not in visited:
            visited.add(nxt)
            stack.append(nxt)
```

广搜。

```python
from collections import deque

q = deque([start])
visited = {start}
while q:
    node = q.popleft()
    for nxt in graph[node]:
        if nxt not in visited:
            visited.add(nxt)
            q.append(nxt)
```

广搜分层，每一轮处理一层。

```python
q = deque([start])
visited = {start}
step = 0
while q:
    for _ in range(len(q)):         # 先记下这一层的节点数
        node = q.popleft()
        for nxt in graph[node]:
            if nxt not in visited:
                visited.add(nxt)
                q.append(nxt)
    step += 1
```

### visited 的两个要点

第一，图必须标记，树不用。树从父到子不会走回来，图里 A 连着 B，B 又连着 A，不标记就会在两点之间来回走，一直递归到栈溢出。

第二，广搜在入队时标记，不要等出队才标记。出队时才标记的话，同一个节点会被多个邻居重复塞进队列，队列会膨胀，层数也会算错。

网格题常用修改原数组来代替 visited。把访问过的陆地改成水，后面再遇到就自动跳过，省掉一个二维数组。

### 拓扑排序模板

```python
from collections import deque

graph = [[] for _ in range(n)]
indeg = [0] * n
for a, b in edges:          # 约定 b 是 a 的前置，边从 b 指向 a
    graph[b].append(a)
    indeg[a] += 1

q = deque([i for i in range(n) if indeg[i] == 0])
done = 0
while q:
    u = q.popleft()
    done += 1
    for v in graph[u]:
        indeg[v] -= 1
        if indeg[v] == 0:
            q.append(v)

ok = (done == n)
```

入度表示还有几个前置没完成。入度归零就入队。最后处理过的节点数等于总数就说明没有环。

### Trie 节点的定义

```python
class Trie:
    def __init__(self):
        self.children = {}      # 字符 到 子节点
        self.is_end = False     # 有没有单词在这里结束
```

字典版通用，字符可以是任意字符。数组版用 `[None] * 26` 更快，但只支持固定的小写字母集。

## Hot 100 四道题

### 200. 岛屿数量 —— 网格深搜

```python
def numIslands(grid):
    if not grid:
        return 0
    m, n = len(grid), len(grid[0])

    def dfs(i, j):
        if i < 0 or i >= m or j < 0 or j >= n:
            return
        if grid[i][j] != "1":
            return
        grid[i][j] = "0"        # 沉掉，顺便当 visited 用
        dfs(i + 1, j)
        dfs(i - 1, j)
        dfs(i, j + 1)
        dfs(i, j - 1)

    count = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == "1":
                count += 1
                dfs(i, j)
    return count
```

- 外层双层循环负责发现新岛屿，内层 dfs 负责把一整个岛屿沉掉
- 每片陆地只会被它第一个被扫到的格子触发一次，计数不会重复
- 易错：忘记沉掉，两个相邻陆地会互相递归，栈溢出；把斜方向也算进去；网格里存的是字符串 `"1"` 而不是数字 1
- 边界：空网格要先返回 0，否则 `len(grid[0])` 报错
- 递归深度可能超过 Python 默认的 1000，稳妥写法是把 dfs 换成显式栈

### 994. 腐烂的橘子 —— 多源广搜

```python
from collections import deque

def orangesRotting(grid):
    m, n = len(grid), len(grid[0])
    q = deque()
    fresh = 0

    for i in range(m):
        for j in range(n):
            if grid[i][j] == 2:
                q.append((i, j))        # 所有腐烂橘子同时当起点
            elif grid[i][j] == 1:
                fresh += 1

    if fresh == 0:                      # 没有新鲜橘子，不需要时间
        return 0

    minutes = 0
    while q and fresh > 0:
        minutes += 1                    # 开始新的一轮扩散
        for _ in range(len(q)):
            x, y = q.popleft()
            for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nx, ny = x + dx, y + dy
                if 0 <= nx < m and 0 <= ny < n and grid[nx][ny] == 1:
                    grid[nx][ny] = 2    # 变成腐烂，顺便当标记
                    fresh -= 1
                    q.append((nx, ny))

    return minutes if fresh == 0 else -1
```

- 多个起点全部入队，一次广搜就够，可以理解成有一个虚拟超级源点连向所有腐烂橘子
- 循环条件带 `fresh > 0`，是为了不让最后一轮空转，否则分钟数会多算 1
- 等价写法是把 minutes 初始化成 -1，进循环先加一，把初始那批橘子当成第 0 轮
- 最容易看懂的写法是队列里存 `(i, j, t)`，新感染的橘子记成 `t + 1`，最后更新的时间就是答案
- 易错：只把第一个腐烂橘子入队；入队时忘记标记，同一个格子被重复入队；一开始 fresh 就是 0 要返回 0 而不是 -1

### 207. 课程表 —— 拓扑排序

```python
from collections import deque

def canFinish(numCourses, prerequisites):
    graph = [[] for _ in range(numCourses)]
    indeg = [0] * numCourses

    for a, b in prerequisites:      # 想学 a，先学 b
        graph[b].append(a)          # 边从 b 指向 a
        indeg[a] += 1

    q = deque([i for i in range(numCourses) if indeg[i] == 0])
    done = 0

    while q:
        u = q.popleft()
        done += 1
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)

    return done == numCourses
```

深搜判环的写法，用三种状态代替布尔数组。

```python
def canFinish(numCourses, prerequisites):
    graph = [[] for _ in range(numCourses)]
    for a, b in prerequisites:
        graph[b].append(a)

    state = [0] * numCourses      # 0 没访问，1 在递归路径上，2 已完成

    def dfs(u):
        if state[u] == 1:         # 撞上正在递归的节点，有环
            return False
        if state[u] == 2:         # 已经验过，安全
            return True
        state[u] = 1
        for v in graph[u]:
            if not dfs(v):
                return False
        state[u] = 2
        return True

    for i in range(numCourses):
        if not dfs(i):
            return False
    return True
```

- 边的方向是这题的关键，`[a, b]` 读成「想学 a 先学 b」，所以边从 b 指向 a
- 能学完所有课程等价于图里没有环，环上节点的入度永远降不到 0
- 深搜版不能只用布尔 visited，有向图里同一个节点可能被多条路径到达，第二次遇到不代表有环，必须区分「在递归路径上」和「已完成」
- 深搜版外面那层 for 不能省，图不一定连通
- 易错：边方向反了。用单个先修关系的例子测不出来，必须用 `[[1, 0], [0, 1]]` 这种有环的用例验证
- 顺带记住 210 课程表 II，把出队顺序记下来就行，长度不够就返回空数组

### 208. 实现 Trie —— 前缀树设计

```python
class Trie:
    def __init__(self):
        self.children = {}
        self.is_end = False

    def insert(self, word):
        node = self
        for ch in word:
            if ch not in node.children:
                node.children[ch] = Trie()   # 没有就新建
            node = node.children[ch]         # 有就走过去
        node.is_end = True

    def _find(self, prefix):
        node = self
        for ch in prefix:
            if ch not in node.children:
                return None
            node = node.children[ch]
        return node

    def search(self, word):
        node = self._find(word)
        return node is not None and node.is_end

    def startsWith(self, prefix):
        return self._find(prefix) is not None
```

- 每个节点只代表一个字符，从根走下来的路径拼起来就是前缀
- 插入 "app" 和 "apple" 之后，前三个节点是共用的，这就是 Trie 省空间的地方
- search 和 startsWith 只差最后一行，一个要看 `is_end`，一个不看
- 为什么不用 set 存所有单词，因为 set 做前缀查询要把每个单词都拿出来比，是 O(N × L)，Trie 是 O(L)，跟单词总数无关
- 易错：search 忘记检查 `is_end`；insert 里漏写 `node = node.children[ch]`；开头写成 `node = Trie()` 而不是 `node = self`；把 `children = {}` 写成类属性，被所有实例共享

## 四题对比

| 题号 | 场景 | 套路 | 时间 | 空间 |
| --- | --- | --- | --- | --- |
| 200 岛屿数量 | 网格，数连通块 | 深搜打标记 | O(mn) | O(mn) |
| 994 腐烂的橘子 | 网格，求扩散轮数 | 多源广搜，分层计数 | O(mn) | O(mn) |
| 207 课程表 | 有向图，判环 | 入度拓扑排序或三色深搜 | O(V + E) | O(V + E) |
| 208 实现 Trie | 字符串集合，按前缀查 | 孩子字典加结束标记 | O(L) 每次操作 | O(总字符数) |

`m`、`n` 是网格的长宽，`V` 是节点数，`E` 是边数，`L` 是单词长度。

## 共同规律

这四题都在解决同一个问题，怎么知道一个位置已经处理过了。

| 题目 | 标记方式 |
| --- | --- |
| 200 | 把陆地的 `"1"` 改成 `"0"` |
| 994 | 把新鲜橘子的 1 改成 2，同时用 fresh 计数 |
| 207 | Kahn 用入度归零，深搜用三色状态 |
| 208 | 用当前走到的节点位置本身表示进度 |

深搜和广搜的分工也很清楚。

- 数连通块、判断能不能走通，用深搜，写起来短
- 求最短、求最少几轮，用广搜，因为广搜一层一层扩，第一次到达就是最短
- 多个起点同时开始，把所有起点一次性入队

写网格题先把方向数组和边界判断写好，写图题先想清楚边的方向。207 的边方向弄反，答案会悄悄出错。
