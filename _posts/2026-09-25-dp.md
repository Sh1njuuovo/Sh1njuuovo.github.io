## 一句话概括

动态规划是把大问题切成许多小问题，把小问题的答案存下来复用。它和暴力递归的关系最近，区别在于同一个子问题只算一次。代码通常很短，难的是想清楚状态和转移。

## 什么时候用它

看到下面这些信号，先想想动态规划。

- 问方案总数、最大最小值、能不能做到
- 每一个决策都依赖前面若干步的结果
- 暴力递归里出现了大量重复的子问题
- 每一步的选择会改变后面能选的集合，而且这个改变不是单调的
- 数据规模在几百到几万之间，平方级别的复杂度可以接受

最后一条很实用。n 在 1000 到 5000 这个量级，往往就是在暗示 O(n^2) 的动态规划。

## 和贪心的区别

| 对比项 | 贪心 | 动态规划 |
| --- | --- | --- |
| 保留多少状态 | 只保留一个当前最优 | 保留所有可能的状态 |
| 是否回头 | 不回头，选了就定了 | 从小规模的最优解一步步推 |
| 关键要求 | 局部最优能推出全局最优 | 有最优子结构和重叠子问题 |
| 典型味道 | 敢丢 | 不遗漏 |

能用动态规划要满足两个条件。第一是问题可以拆，大问题的答案能从更小问题的答案推出来，而且推法一样。第二是子问题会重复，同一个子问题被反复问到。少一个都用不上动态规划。

## 四步走

动态规划的代码短，难的是想清楚。按下面四步走，思路不容易乱。

1. 定状态。想清楚「要回答的子问题是什么」，用下标把它标出来
2. 写转移。问自己最后一步做了什么选择，把几种情况都写出来，看当前状态能从哪些更小的状态推过来
3. 定初始化。最小的那些子问题没法再往前推，直接把答案写死
4. 定顺序。保证算某个状态时，它依赖的状态已经算好了

最后还要确定答案在哪个状态里。有时候是 dp[n]，有时候是 dp[n-1]，有时候是整个数组取最大值。

用斐波那契数列演示一遍。暴力递归是 `fib(n)` 等于 `fib(n-1)` 加 `fib(n-2)`，时间是 O(2^n)，因为 `fib(3)` 这样的子问题会被反复算很多遍。

按四步走。状态方面，dp[i] 表示第 i 项的值。转移方面，dp[i] 等于 dp[i-1] 加上 dp[i-2]。初始化方面，dp[0] 等于 0，dp[1] 等于 1。顺序方面，i 从小到大。答案是 dp[n]。

## 核心模板

### 模板一，只依赖前一步或前两步

```python
def solve(n):
    dp = [0] * (n + 1)      # 初始值按题目要求设置
    dp[0] = 1               # 最小的子问题先填好
    for i in range(1, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]    # 换成真正的转移式
    return dp[n]
```

因为每个状态只用到前面常数个状态，通常可以压成几个变量滚动的写法。70、198、152 都属于这一类。

### 模板二，外层遍历状态，内层枚举选择

```python
def solve2(n, items):
    dp = [float('inf')] * (n + 1)
    dp[0] = 0
    for i in range(1, n + 1):
        for x in items:
            if x <= i:
                dp[i] = min(dp[i], dp[i - x] + 1)
    return dp[n]
```

外层是要凑的目标或者要处理的位置，内层枚举最后一个用的物品或者这一步做的选择。279、322、416 用的都是这个骨架。

背包类题目有一个必须记牢的差别。物品只能用一次的时候，容量要倒序遍历。物品可以重复使用的时候，容量正序遍历。416 是前一种，279 和 322 是后一种。

### 模板三，往回看一段

```python
def solve3(nums):
    n = len(nums)
    dp = [1] * n
    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

内层不在枚举固定的物品，而是往回看每一个可能的前继位置。139、300、32 都是这个形状，转移的代价是 O(n)，所以整体通常是 O(n^2)。

## Python 基础

### 数组的初始化

```python
dp = [0] * (n + 1)              # 求最大值，初值 0
dp = [float('inf')] * (n + 1)   # 求最小值，初值正无穷
dp = [False] * (n + 1)          # 求可行性，初值 False
```

下标开成 n 加 1 很常见，好处是 dp[0] 留给「什么都没有」的空情况，处理边界时不用特判。322 和 416 都用了这个技巧。

### 二维数组的浅拷贝坑

```python
dp = [[0] * (n + 1) for _ in range(m + 1)]   # 正确，每行是独立的列表
dp = [[0] * (n + 1)] * (m + 1)               # 错误，所有行指向同一个列表
```

带星号的写法是浅拷贝，改其中一行其他行会跟着变，而且不会报错。二维数组一定要用列表推导式。

### 记忆化

记忆化就是在递归上加一层缓存，算过的子问题直接返回结果。

- 装饰器写法是 `@lru_cache(maxsize=None)`，放在函数定义上面
- 参数必须是可哈希的，列表和字典不能直接传进去，要换成下标或者元组
- 好处是不用自己确定遍历顺序，递归天然保证依赖先算好，适合先把思路写对再改递推
- 缺点是递归层数深的时候会爆栈，Python 默认上限是一千左右

### 空间压缩

```python
prev, cur = 0, 1
for _ in range(2, n + 1):
    prev, cur = cur, prev + cur
```

两个变量的写法必须用一条语句同时赋值。写成两行的话，`prev` 会先被覆盖，后面加的就不对了。

## 复杂度怎么算

时间是状态总数乘以每个状态的转移代价，空间是数组大小。

状态总数一般就是数组大小，一维是 n，二维是 n 平方。转移代价是每个状态枚举多少种选择。先估出这两个数字再动手写，能提前发现思路会不会超时。

## 常见的状态长相

| 类型 | 状态长什么样 | 这一篇里的题 |
| --- | --- | --- |
| 线性递推 | dp[i] 只依赖前面一两个状态 | 70 爬楼梯、198 打家劫舍、152 乘积最大子数组 |
| 完全背包 | dp[容量]，物品可以反复用 | 279 完全平方数、322 零钱兑换 |
| 零一背包 | dp[容量]，物品只能用一次 | 416 分割等和子集 |
| 字符串前缀 | dp[i] 表示前 i 个字符的结果 | 139 单词拆分、32 最长有效括号 |
| 子序列 | dp[i] 表示以 i 结尾的最优值 | 300 最长递增子序列 |
| 二维填表 | dp[i][j] 表示某一行某一列的结果 | 118 杨辉三角 |

两个词要分清楚。子数组和子串指连续的一段，子序列不要求连续但要保持原有顺序。152 求的是连续段，300 求的是子序列，题面用词直接决定了转移的范围。

## Hot 100 十道题

### 70. 爬楼梯

```python
def climbStairs(n):
    dp = [0] * (n + 1)
    dp[0] = 1   # 站在地面上，本身就是一种状态
    dp[1] = 1   # 到第 1 级只有一种走法

    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]

    return dp[n]
```

- 状态是爬到第 i 级的走法数，转移按最后一步分类，最后一步要么走 1 级要么走 2 级
- 两类不重叠也不遗漏，所以可以直接相加。计数型动态规划都要做这两句检查
- dp[0] 等于 1 不是凭空写的，它对应「站在地面直接走 2 级到第 2 级」这条真实路径
- 数组开成 n 加 1 之后，n 等于 1 时循环不执行，不用额外特判
- 只依赖前两个状态，可以压成两个变量滚动，空间降到 O(1)
- 复杂度 O(n) 时间，O(n) 空间，压缩后 O(1)

### 118. 杨辉三角

```python
def generate(numRows):
    triangle = []

    for i in range(numRows):
        row = [1] * (i + 1)          # 首尾和整行都先填 1
        for j in range(1, i):        # 中间的位置才需要算
            row[j] = triangle[i - 1][j - 1] + triangle[i - 1][j]
        triangle.append(row)

    return triangle
```

- 这是这一批里唯一的二维填表题，dp[i][j] 等于上一行相邻两个数之和
- 首尾固定是 1，提前把整行填成 1 可以省掉边界判断
- 内层写 `range(1, i)`，右端不取 i，正好避开最后一个位置
- 前两行天然不进内层循环，i 等于 0 和 i 等于 1 时范围都是空的
- 复杂度 O(n^2) 时间，空间也是 O(n^2)，主要是返回的二维列表本身

### 198. 打家劫舍

```python
def rob(nums):
    n = len(nums)
    dp = [0] * (n + 1)
    dp[1] = nums[0]

    for i in range(2, n + 1):
        dp[i] = max(dp[i - 1], dp[i - 2] + nums[i - 1])

    return dp[n]
```

- 状态是前 i 间房能偷到的最大金额，转移按第 i 间偷不偷分类
- 偷的话，第 i 减 1 间一定不能偷，所以用 dp[i-2] 加 nums[i-1]
- dp 的下标比 nums 大 1，dp[i] 对应 nums[i-1]，这个错位是主要的下标陷阱
- dp[1] 必须显式赋值，数组默认是 0，不赋值会把第一间房的钱丢掉
- 复杂度 O(n) 时间，空间 O(n)，可以压缩成两个变量做到 O(1)

### 279. 完全平方数

```python
def numSquares(n):
    dp = [float('inf')] * (n + 1)
    dp[0] = 0

    for i in range(1, n + 1):
        k = 1
        while k * k <= i:
            dp[i] = min(dp[i], dp[i - k * k] + 1)
            k += 1

    return dp[n]
```

- 可以理解成用 1、4、9、16 这些面额凑出 n，每个面额可用无限次，是求最少物品数的完全背包
- 内层边界要写 `k * k <= i`，取等号那一项对应 i 本身是完全平方数的情况，漏掉答案会偏大
- 初值用正无穷，dp[0] 等于 0。dp[0] 写错的话整张表都会算不出来
- 易错：用贪心每次拿最大的平方数。n 等于 12 时贪心得到 4 个，最优是三个 4
- 复杂度 O(n 乘以根号 n) 时间，O(n) 空间

### 322. 零钱兑换

```python
def coinChange(coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0

    for i in range(1, amount + 1):
        for coin in coins:
            if coin <= i:
                dp[i] = min(dp[i], dp[i - coin] + 1)

    return dp[amount] if dp[amount] != float('inf') else -1
```

- 和 279 是同一个模板，区别在物品集合是给定的硬币数组，而且可能凑不出来
- 硬币面额大于当前金额时要跳过，否则下标变成负数。Python 里负下标不报错，会静默取到后面的元素
- 返回前要判断 dp[amount] 是不是还是正无穷，是的话返回 -1
- 易错：用贪心每次拿最大面额。coins 是 [1, 3, 4]、amount 是 6 时贪心要三枚，最优是两枚
- 复杂度 O(amount 乘以硬币种类数) 时间，O(amount) 空间

### 139. 单词拆分

```python
def wordBreak(s, wordDict):
    words = set(wordDict)
    n = len(s)
    dp = [False] * (n + 1)
    dp[0] = True

    for i in range(1, n + 1):
        for j in range(i):
            if dp[j] and s[j:i] in words:
                dp[i] = True
                break

    return dp[n]
```

- 状态是前 i 个字符能不能拼出来，转移是枚举最后一段单词的起点 j
- 判断条件有两个，前面一段能拼出来，并且 s[j:i] 正好在词典里，缺一个都不行
- dp[0] 等于 True 表示空串可以拼出来。写成 False 的话整张表全是 False
- 词典要先转成 set，用 list 做 in 判断是 O(k) 的查找
- 复杂度是 O(n^2) 次转移，每次要做一次切片，严格算起来最坏 O(n^3)。空间 O(n)

### 300. 最长递增子序列

```python
def lengthOfLIS(nums):
    n = len(nums)
    dp = [1] * n

    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)

    return max(dp)
```

- 子序列不要求连续，所以状态必须定义成「以 i 结尾」，否则结尾元素不确定，转移写不出来
- dp 初值是 1，每个元素自己就是长度 1 的子序列
- 返回的是 max(dp) 而不是最后一个元素，最长的那条不一定停在末尾
- 比较用严格小于，题目要求严格递增
- 复杂度 O(n^2) 时间，O(n) 空间。还有 O(n log n) 的二分写法，只能求长度不能还原序列

### 152. 乘积最大子数组

```python
def maxProduct(nums):
    cur_max = cur_min = ans = nums[0]

    for x in nums[1:]:
        candidates = (x, cur_max * x, cur_min * x)
        cur_max = max(candidates)
        cur_min = min(candidates)
        ans = max(ans, cur_max)

    return ans
```

- 求的是连续的一段，状态定义成「以 i 结尾」，转移只看前一个位置
- 负数会让大小关系翻转，之前的最小值乘上负数可能变成最大值，所以要同时维护 cur_max 和 cur_min
- 先把三个候选装进元组再分别取最大最小，这样不会用到被覆盖的新值
- 三个候选里必须包含 x 自己，对应从前一段断开、从当前位置重新开始的情况
- 返回 ans 而不是 cur_max，全局最大值可能出现在中间某一段
- 复杂度 O(n) 时间，O(1) 空间

### 416. 分割等和子集

```python
def canPartition(nums):
    total = sum(nums)
    if total % 2 != 0:
        return False

    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True

    for num in nums:
        for j in range(target, num - 1, -1):
            dp[j] = dp[j] or dp[j - num]

    return dp[target]
```

- 两组和相等等价于能不能从数组里选出一些数凑出总和的一半，这是零一背包的判定型写法
- 总和是奇数直接返回 False，target 要用整除而不是除法，除法在 Python 3 里得到浮点数
- 内层必须倒序遍历容量，正序会让同一个数被重复使用，把零一背包写成完全背包
- 内层上界写 `num - 1`，这样 j 等于 num 的那一格也能更新到，对应只选当前这个数
- 复杂度 O(n 乘以 target) 时间，O(target) 空间

### 32. 最长有效括号

```python
def longestValidParentheses(s):
    n = len(s)
    dp = [0] * n
    best = 0

    for i in range(1, n):
        if s[i] == ')':
            if s[i - 1] == '(':
                prev = dp[i - 2] if i >= 2 else 0
                dp[i] = prev + 2
            else:
                j = i - dp[i - 1] - 1
                if j >= 0 and s[j] == '(':
                    front = dp[j - 1] if j >= 1 else 0
                    dp[i] = dp[i - 1] + 2 + front
            best = max(best, dp[i])

    return best
```

- 状态是以 i 结尾的最长有效括号长度。左括号结尾一定是 0，只有右括号结尾才可能有长度
- 右括号左边是左括号时，直接成对，长度等于 dp[i-2] 加 2
- 右括号左边也是右括号时，先跨过 dp[i-1] 那一段，再看跨过去的位置是不是左括号
- 第三种情况还要加上跨过去位置之前的 dp[j-1]，否则前面已经算好的那一段就丢了
- 返回 max(dp) 而不是最后一个元素，最长的一段不一定停在末尾
- 写 `dp[i - 2]` 之前必须判断 i 大于等于 2。Python 里 dp[-1] 不报错，会静默取到数组最后一个元素
- 复杂度 O(n) 时间，O(n) 空间。栈写法和两次遍历计数法也是 O(n)，这里不展开

## 常见易错点

第一，状态定义含糊。写完转移还是说不清 dp[i] 到底代表什么，多半是状态没定义好。判断标准是，这个状态能不能单独回答一个问题。

第二，漏了初始化。dp[0] 或者第一行第一列忘记填，后面的结果全被错误初值污染。70 的 dp[0] 等于 1、198 的 dp[1] 等于 nums[0] 都必须显式写出来。

第三，初值的方向弄反。求最小值用正无穷，求最大值用 0 或者负无穷。279 和 322 的 dp[0] 都是 0，其余位置必须是正无穷。

第四，二维数组写成浅拷贝。`[[0] * n] * m` 会让所有行共用一份数据。

第五，遍历顺序反了。零一背包必须倒序遍历容量，完全背包正序遍历。139 的 dp 必须从小到大填。

第六，dp 下标和输入下标错位。198、139 的 dp 都比输入长 1，dp[i] 对应的是输入的前 i 个元素。

第七，答案位置写错。152 返回 ans，300 和 32 返回 max(dp)，70、198、139 返回 dp[n]。想清楚最后一个状态代表什么再返回。

第八，数组下标越界或者被 Python 的负下标救回来。32 里写 `dp[i - 2]` 之前一定要判断 i 是否大于等于 2，否则 dp[-1] 会静默取到最后一个元素。

第九，一个状态不够用。152 因为负数会翻转大小关系，必须同时维护最大值和最小值。

第十，更新顺序写反。152 要先把三个候选都算出来再更新，写反了就会用到被覆盖的新值。

## 共同规律

这十道题按「每个状态要看多远」分成四类。

第一类，只看前一两步。70、152 属于这一类。状态定义成「以 i 结尾」或者「到第 i 级」，转移只用到前面一两个位置，所以可以压成几个变量滚动，空间是 O(1)。

第二类，内层枚举选择。198、279、322、416 属于这一类。共同骨架是外层遍历状态，内层枚举最后一个用的物品或者这一步做的选择，转移代价等于选择的个数。这四道题里 198 是选或不选，279 和 322 是完全背包，416 是零一背包。

第三类，往回看一段。139、300、32 属于这一类。内层要遍历前面的每一个位置，转移代价是 O(n)，所以整体通常是 O(n^2)。这三道题的状态都定义成「以 i 结尾」或者「前 i 个」。

第四类，二维填表。118 属于这一类，状态有两个下标，每一行依赖上一行。

答案的位置有规律可循。问最多能拿多少这类可以累加的题，答案通常在最后一个状态，比如 198、416、139。问最长的一段这类题，答案可能出现在任何位置，所以要取 max，比如 300 和 32。

判断信号可以这样记。

- 问方案总数，每一步的选择数固定，想 70 这类
- 问能不能凑出某个值、每个元素只能用一次，想 416 这类零一背包
- 问凑出某个值的最少个数、元素可以重复用，想 279 和 322 这类完全背包
- 问最长的一段或者最长的序列，并且那段不一定停在末尾，状态定义成「以 i 结尾」，答案取 max

多维动态规划是单独的一篇，题单里的 62 不同路径、64 最小路径和、5 最长回文子串、1143 最长公共子序列、72 编辑距离会放在那里整理。状态从一维变成二维之后，多出来的那一步是分清两个下标分别代表什么。
