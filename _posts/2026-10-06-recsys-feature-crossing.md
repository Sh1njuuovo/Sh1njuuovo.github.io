**特征交叉**是对多个单独特征进行组合（内积、外积、笛卡尔积、Hadamard 积等）来合成特征的过程，实现对样本空间的非线性变换，从而增加模型的非线性能力。

特征交叉的好处：

- 捕获特征间的**共现关系**（如「年轻男性 × 数码类目」），提升模型准确度
- 生成新特征、甚至未知的特征组合，提升模型泛化能力
- 现实世界高度非线性，交叉方式可以提升模型的非线性表达能力

## 1. FM（Factorization Machine，因子分解机）

### 线性模型

线性模型对输入特征取加权和作为预估：

1. 有 d 个特征 x = (x₁,...,x_d)
2. 线性模型公式：`p = b + Σ_{i=1..d} w_i·x_i`
3. 有 d+1 个参数：权重 w = (w₁,...,w_d) 和偏置 b
4. 预测只是特征的加权和——**只有加、没有乘**

### 二阶交叉特征（POLY2）

如果先做特征交叉再用线性模型，效果通常更好：

1. 有 d 个特征
2. 二阶特征交叉项：x_i·x_j（i < j）
3. 线性模型 + 二阶交叉：

```
p = b + Σ w_i·x_i + Σ_i Σ_{j>i} u_ij·x_i·x_j
```

4. 模型参数 O(d²)，主要来自二阶交叉权重 u_ij

特征交叉让线性模型的特征不只是相加、还能相乘，有效提升表达能力。

### FM：低秩分解

实际做二阶交叉时，参数多导致计算量大、还容易过拟合。FM 的改进：

1. 二阶交叉权重 u_ij 组成一个 d×d 的权重矩阵 U
2. U 是 d×d 维对称矩阵，可以做**低秩矩阵分解**：U ≈ V·Vᵀ，V 是 d×k 维矩阵
3. 于是 u_ij ≈ <v_i, v_j>，替换原公式得到 FM：

```
p = b + Σ w_i·x_i + Σ_i Σ_{j>i} <v_i, v_j>·x_i·x_j
```

4. FM 参数 O(kd)，其中 k << d

FM 的主要优点：

1. 是线性模型的替代品：能用线性回归、逻辑回归的场景都可以用 FM
2. 使用二阶交叉特征，表达能力比线性模型更强
3. 通过近似 `u_ij ≈ <v_i,v_j>`，把二阶交叉权重数量从 O(d²) 降到 O(kd)，大大加速计算

> Tip：现在业界早已不再直接用 FM 做特征交叉了，但它的思想（低秩分解代替全参数交叉）是后续模型的基础。

参考文献：Rendle, *Factorization Machines*, ICDM 2010。

## 2. DCN（Deep & Cross Network，深度交叉网络）

召回双塔、粗排三塔、精排（MMoE 的专家网络）中的神经网络都可以替换成全连接网络、DCN 或任何更好的网络结构。DCN 由一个**深度网络**和一个**交叉网络**组成，交叉网络的基本组成单元是**交叉层（Cross Layer）**，这是本节最重要的内容。

### 交叉层

设初始输入向量 x_0 经过若干层神经网络后输出 x_l（两者都是交叉层的输入），单个交叉层的流程：

1. 将向量 x_l 输入全连接层，输出 W_l·x_l + b_l
2. 初始输入 x_0 与全连接层输出做 **Hadamard 乘积**（对应位置逐个元素相乘）
3. 把结果与 x_l 加和（残差），得到交叉层输出 x_{l+1}

公式：

```
x_{l+1} = x_0 ∘ (W_l·x_l + b_l) + x_l
```

交叉层的主要参数在其中的全连接层（W_l、b_l），求和与 Hadamard 乘积都不涉及参数。

### 交叉网络

第一个交叉层的输入只有初始向量 x_0，输出为 `x_1 = x_0 ∘ (W₀·x₀ + b₀) + x₀`。之后按实际需要多次叠加交叉层，得到 x_0 → x_1 → ... → x_L（每个交叉层有自己的参数）。这就是 Cross Network V2 的基本架构。

### 深度交叉网络

```
用户特征 + 物品特征 + 其它特征（拼接）
        │                        │
    全连接网络（deep）        交叉网络（cross）
        │                        │
        └──────── Concatenate ────┘
                    │
                全连接层
                    │
                 输出
```

基本思想：把用户和物品的特征拼接起来，分别输入全连接网络和交叉网络，再把两个网络的输出拼接后输入全连接层，得到最终输出。深度网络做隐式非线性，交叉网络做显式交叉。

参考文献：Wang et al., *DCN V2*, WWW 2021；Wang et al., *Deep & Cross Network*, ADKDD 2017。

## 3. LHUC / PPNet

LHUC（Learning Hidden Unit Contributions）是一种神经网络结构，与 DCN 的思想有些类似，可用于精排。它起源于语音识别，后来被应用到推荐系统，快手将其称为 PPNet，现在已在业界广泛落地。

### 语音识别中的 LHUC

语音识别的输入是一段**语音信号**，目标是把它变换成能识别文字的表征。不同人的语速、腔调不同，需要加入个性化因素，把**说话者的特征**也作为输入。架构如下：

```
说话者特征 → 神经网络1 → [多个全连接层] → [Sigmoid × 2] → 缩放向量
说话者特征 → 神经网络2 → [多个全连接层] → [Sigmoid × 2] → 缩放向量
                                                  │ Hadamard 乘积
语音信号 → 全连接层 → 全连接层 → ... ←─────────────┘
```

要点：

1. 图中生成缩放的「神经网络」输入是说话者特征，与处理语音信号的全连接层不同
2. 缩放网络的结构是多个全连接层 + Sigmoid 变换后乘以 2：输出值域 (0,2)，与语音信号隐层做 Hadamard 乘积时，可以放大（>1）或缩小（<1）隐层单元，实现个性化
3. 需要更深网络时可以继续叠加同样操作

### 推荐系统排序模型中的 LHUC（PPNet）

在精排中，把「语音信号」替换为「**物品特征**」、「说话者的特征」替换为「**用户特征**」，其他结构不变：

```
用户特征 → 神经网络 → [Sigmoid × 2] → 缩放向量
                                            │ Hadamard 乘积
物品特征 → 全连接层 → 全连接层 → ... ←──────┘
```

语义：物品特征主网络对所有用户共享，用户特征生成缩放向量逐层调制隐层——同一物品对不同用户，隐层激活幅度不同，实现轻量个性化。

参考文献：Swietojanski et al., IEEE/ACM TASLP 2016；快手《快手落地万亿参数推荐精排模型》（PPNet），2021。

## 4. SENet & Bilinear Cross

SENet 和 Bilinear Cross 一般应用在排序模型中，都有一定正收益。

### SENet

SENet 来自计算机视觉（CV），在推荐系统中用于对特征做**动态加权**：

输入是 m×k 维矩阵，每一行是用户/物品某个特征的 embedding。经过一系列变换得到 m×1 的权重矩阵，再和原矩阵做 **row-wise multiply**（按行相乘），结果与原矩阵维数一致，相当于给每一行（每个特征）赋予不同权重，调整矩阵元素的值。

具体流程：

```
输入 m×k 的 embedding 矩阵
  → AvgPool：每个 field 压缩成 1 个数，得到 m×1
  → FC + ReLU：降到 m/r（r 是压缩比）
  → FC + Sigmoid：升回 m×1 权重向量
  → row-wise multiply：权重按行乘回 m×k
```

SENet 的基本思想：

1. 对离散特征做 **field-wise 加权**
2. field 的定义：若某特征的 embedding 是 64 维向量，这 64 个元素归为一个 field，共享同一个权重
3. 有 m 个 field，权重向量就是 m 维的
4. 不同特征的 embedding 向量维度可以不同

### Bilinear Cross

内积和 Hadamard 乘积都是 field 间简单的特征交叉。设两个 field 均为 k 维向量 x_i、x_j：

```
内积：         f_ij = <x_i, x_j>            （得到 1 个实数）
Hadamard 乘积： f_ij = x_i ∘ x_j             （得到 1 个 k 维向量）
```

局限：

- 有 m 个 field，内积得到 C(m,2) 个实数、Hadamard 得到 C(m,2) 个向量，**数据量爆炸**，必须人工选少数向量参与
- 参与交叉的两个 field **形状（维度）不一样时**，无法求内积和 Hadamard 乘积

基于这两种方法的改进——**Bilinear Cross**（设 x_i 是 k₁ 维、x_j 是 k₂ 维）：

```
基于内积的 Bilinear：    f_ij = x_iᵀ · W_ij · x_j      （W_ij 是 k₁×k₂ 参数矩阵）
基于 Hadamard 的 Bilinear： f_ij = x_i ∘ (W_ij · x_j)   （W_ij 是 k×k 参数矩阵）
```

同样存在局限：m 个 field 时第一种方法要保存 C(m,2) 个参数矩阵，数据量过大，需要人工特征选择或矩阵分解；第二种方法得到 C(m,2) 个向量，也需要人工筛选。

### FiBiNet

FiBiNet 是 SENet 与 Bilinear Cross 的结合：

```
离散特征 → Embedding ──→ Bilinear（原始 embedding 两两交叉）
          └→ SENet（embedding 动态加权）──→ Bilinear（加权后交叉）
                                      ↓ Concatenate
                    原始 + 交叉结果 + 连续特征 → 上层网络
```

与排序模型的主要区别在**离散特征的处理**：引入 Bilinear Cross 做特征交叉，用 SENet 对 embedding 做动态加权。

> Tip：小红书的实际应用没有照搬 FiBiNet，做了多处调整优化——比如认为 SENet 之后的 Bilinear Cross 无意义而省略。

参考文献：Hu et al., SENet, CVPR 2018；Huang et al., FiBiNET, RecSys 2019。

## 5. 本章小结

本篇记录特征交叉及基于特征交叉改进的模型。

特征交叉有利于捕获特征间的共现关系，提升模型准确度；可以生成新的、甚至未知的特征组合，提升泛化能力；现实世界高度非线性，内积、外积、Hadamard 积、Bilinear 等交叉方式能提升模型的非线性能力。

早年的 FM 基于「线性模型 + 二阶交叉特征」，用低秩矩阵分解把交叉权重矩阵近似分解为两个低秩矩阵，减少计算量、防止过拟合。不过业界早已不再直接使用 FM。

随后介绍了两种可替换召回/排序模型内部神经网络的架构，都基于 Hadamard 积和特征交叉：

- **DCN**：可用于召回和排序。由深度网络和交叉网络组成；交叉网络的基本单元是交叉层，即对输入特征做特征交叉；整体把用户和物品特征拼接后分别输入全连接网络和交叉网络，拼接输出再过全连接层
- **LHUC**：用于精排。源于语音识别；推荐系统中用物品特征过主网络、用户特征生成缩放，两类特征做交叉，思想与 DCN 类似但机制不同——用「多层全连接 + Sigmoid×2」生成权重调整物品表征，实现个性化

最后介绍 SENet 与 Bilinear Cross 组合的 **FiBiNet**，常用于排序。它与普通排序模型的区别主要在离散特征处理：引入 Bilinear Cross 做特征交叉、用 SENet 做 embedding 动态加权。小红书落地时没有照搬，做了诸多调整。

## 复习速记

- 特征交叉：组合多个特征（内积/外积/Hadamard/笛卡尔积），做非线性变换；好处是捕获共现、生成新组合、提升泛化
- FM：线性 + 二阶交叉（POLY2），`u_ij ≈ <v_i,v_j>` 低秩分解，参数 O(d²) → O(kd)；能用于任何逻辑回归场景，但现已很少直接用
- DCN 交叉层：`x_{l+1} = x_0 ∘ (W_l·x_l + b_l) + x_l`——参数只在全连接层，Hadamard 和残差加和都无参数
- DCN：deep + cross 并联，输出 concat 再过全连接层；可用在召回/排序的塔或专家网络里
- LHUC/PPNet：说话者/用户特征经「多个全连接层 + Sigmoid×2」生成 (0,2) 缩放，Hadamard 逐层调制主网络隐层，实现个性化
- SENet：AvgPool（squeeze）+ FC+ReLU + FC+Sigmoid（excitation），field-wise 加权，每行一个权重，不同 field 维度可以不同
- 内积/Hadamard 的局限：只能同维度 field、输出爆炸需人工筛选；Bilinear 用参数矩阵 W 解决维度不匹配，更灵活但参数更多
- FiBiNet = Embedding 原始交叉 + SENet 加权后交叉 + 连续特征 → 上层网络；小红书落地有删改（省略 SENet 后的 Bilinear）
