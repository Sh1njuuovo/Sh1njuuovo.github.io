## 一句话概括

只给一个数组，没有哈希或窗口的明显特征，考的是对数组本身的操作能力。这一组的共性，是在少量遍历里用尽量小的额外空间把答案算出来。

## 怎么选工具

- 连续子数组求最值 → 一次遍历维护状态（Kadane）
- 一堆区间求合并 / 覆盖 → 先排序，再线性扫描
- 要求原地平移、原地翻转 → 三次翻转，或循环置换
- 每个位置要用到它左边和右边的信息 → 前缀后缀各扫一遍
- 值域是 1 到 n 且要 O(1) 空间 → 原地哈希

## Python 基础：列表操作速查

### 引用与复制

```python
a = [1, 2, 3]
b = a          # b 和 a 是同一个列表，改 b 就是改 a
c = a[:]       # 切片才是新列表
```

题目说「原地修改」，指不能把结果装进新列表返回，要通过 `nums[i] = ...` 或 `nums[:] = ...` 改动原对象。

### 原地和新列表的区别

| 想做的事 | 返回新列表 | 原地修改 |
| --- | --- | --- |
| 排序 | `sorted(nums)` | `nums.sort()` |
| 反转 | `nums[::-1]` | `nums.reverse()` |
| 整体替换内容 | `new = [...]` | `nums[:] = [...]` |

坑：`nums = sorted(nums)` 只是让名字指向新列表，原列表没变。要原地就写 `nums.sort()` 或 `nums[:] = sorted(nums)`。

### 常用的几行

```python
nums[i], nums[j] = nums[j], nums[i]     # 一步交换，不用临时变量

for i in range(len(nums)):              # 只要下标
for i, x in enumerate(nums):            # 下标和值
for x, y in zip(nums1, nums2):          # 同时走两个数组

float('-inf')                           # 负无穷，作最大值起点
float('inf')                            # 正无穷，作最小值起点

k %= n                                  # 下标绕圈，先取模再算
```

Python 的整数不会溢出，累加时不用担心越界。

## Hot 100 五道题

### 53. 最大子数组和 —— 一次遍历维护状态

```python
def maxSubArray(nums):
    cur = nums[0]        # 以当前位置结尾的最大和
    best = nums[0]       # 全局最大
    for i in range(1, len(nums)):
        cur = max(nums[i], cur + nums[i])
        best = max(best, cur)
    return best
```

- 定义 `f(i)` 为以 `nums[i]` 结尾的最大子数组和，递推式 `f(i) = max(nums[i], f(i-1) + nums[i])`
- 只枚举「结尾」这一个变量，因为每个子数组的结尾位置唯一，左边那一大段可以压缩成一个状态
- `cur` 前面是负数就断掉重新开始，是正数就接上
- 易错：`best` 不能初始化成 0（数组可能全是负数）；`best = max(best, cur)` 不能漏，否则返回的是 `f(n-1)`

另一种等价写法（`cur` 表示「还值得继续用的和」，小于 0 就清零）：

```python
def maxSubArray(nums):
    best = float('-inf')
    cur = 0
    for x in nums:
        cur += x
        best = max(best, cur)
        if cur < 0:
            cur = 0
    return best
```

### 56. 合并区间 —— 排序 + 线性扫描

```python
def merge(intervals):
    intervals.sort(key=lambda x: x[0])
    res = []
    for start, end in intervals:
        if res and start <= res[-1][1]:
            res[-1][1] = max(res[-1][1], end)
        else:
            res.append([start, end])
    return res
```

- 排序之后，互相重叠的区间一定排成连续的一段，所以扫一遍就够，不用回头找
- 判断重叠用 `start <= 当前右端`，边界相等也算重叠，`[1,4]` 和 `[4,5]` 要合成 `[1,5]`
- 易错：拉长右端必须取 `max`，后面的区间可能整个被包含，写成 `cur_end = end` 会把区间缩回去；用两个变量维护当前段时，循环结束后别忘了把最后一段收进结果

### 189. 轮转数组 —— 三次翻转

```python
def rotate(nums, k):
    n = len(nums)
    k %= n

    def reverse(left, right):
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1

    reverse(0, n - 1)
    reverse(0, k - 1)
    reverse(k, n - 1)
```

- 把数组看成 `A + B`，目标是 `B + A`。整体翻转得到 `rev(B) + rev(A)`，再分别翻回两段内部，就得到 `B + A`
- 第 2 步翻前 `k` 个，因为 `rev(B)` 的长度正好是 `k`
- 易错：先 `k %= n`，否则 `k` 大于 `n` 时下标都失效；`k` 取模后为 0 时 `reverse(0, k-1)` 会变成 `reverse(0, -1)`，要提前返回；`nums = nums[-k:] + nums[:-k]` 不修改原数组，也不满足 O(1) 空间
- 另一种 O(1) 做法是循环置换，每个值直接跳到 `(i + k) % n`。`n` 和 `k` 不互质时会分成 `gcd(n, k)` 条圈，所以每条圈回到起点后要从下一个起点重开，用一个 `count` 数够 `n` 个元素才停

### 238. 除自身以外数组的乘积 —— 前缀后缀两次遍历

```python
def productExceptSelf(nums):
    n = len(nums)
    ans = [1] * n

    for i in range(1, n):          # ans[i] 先装左边所有数的乘积
        ans[i] = ans[i - 1] * nums[i - 1]

    r = 1                          # r 始终表示「i 右边所有数的乘积」
    for i in range(n - 1, -1, -1):
        ans[i] *= r
        r *= nums[i]

    return ans
```

- 拆开看：`answer[i] = 左边的乘积 × 右边的乘积`
- 输出数组先当左边那半用，第二遍用一个变量 `r` 把右边乘进去，额外空间降到 O(1)
- 易错：初始值都写 1（空乘积是 1）；第二遍顺序是先 `ans[i] *= r` 再 `r *= nums[i]`，`r` 不能把当前数算进去；题目禁止除法，总乘积除以自己这条路的 0 情形很难处理

### 41. 缺失的第一个正数 —— 原地哈希

```python
def firstMissingPositive(nums):
    n = len(nums)

    for i in range(n):
        while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
            j = nums[i] - 1
            nums[i], nums[j] = nums[j], nums[i]

    for i in range(n):
        if nums[i] != i + 1:
            return i + 1

    return n + 1
```

- 关键观察：`n` 个数的答案一定在 `1` 到 `n + 1` 之间，搜索空间被缩小
- 规定值 `v` 应该待在下标 `v - 1`，用反复交换把值送回家，数组自己就是哈希表
- 内层 `while` 加起来只跑 O(n) 次，因为每次成功交换都会让一个值永久归位，之后不会再被换走
- 易错：`while` 条件里的 `nums[nums[i] - 1] != nums[i]` 不能省，有重复元素时会死循环；不能用 `if` 代替 `while`，换过来的新值可能还没归位；最后要兜底 `return n + 1`

## 五题对比

| 题号 | 问什么 | 套路 | 时间 | 额外空间 |
| --- | --- | --- | --- | --- |
| 53 | 最大和的连续子数组 | 一次遍历维护状态 | O(n) | O(1) |
| 56 | 合并重叠区间 | 排序 + 扫描 | O(n log n) | O(log n) |

## 共同规律

这五题都不靠额外的数据结构，靠的是换个角度看数组本身。

- 53 只枚举右端点，把左边那段压成一个滚动状态
- 56 先排序，让重叠的区间变成连续的一段
- 189 把数组切成两段，用翻转的性质完成整体平移
- 238 把答案拆成左边和右边两半，各扫一遍
- 41 用下标当 key，把值送到 `v - 1` 的位置

遇到「原地」「O(1) 额外空间」「连续」这类要求时，先想想能不能用下标本身携带信息，或者用两次遍历代替额外存储。
