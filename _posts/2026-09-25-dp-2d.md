## 一句话概括

一个 dp[i] 不够用了，子问题需要两个参数才能说清楚，就上二维状态。四步走和一维完全一样，变的是状态的定义和遍历顺序。

## 什么时候用它

看到下面这些场景，先想想二维状态。

- 题目里出现网格、地图、从左上角走到右下角、只能往右或者往下
- 题目给两个字符串，问公共的、编辑的、变换的代价或者长度
- 题目问某个区间是不是回文、区间上的最优值
- 一维状态推不动，发现缺了一个信息，那个信息往往就是第二维

## 第二维的三种含义

| 类型 | dp[i][j] 的含义 | 这一篇里的题 |
| --- | --- | --- |
| 网格类 | 走到格子 (i, j) 的结果 | 62 不同路径、64 最小路径和 |
| 双序列类 | 第一个串取前 i 个、第二个串取前 j 个的结果 | 1143 最长公共子序列、72 编辑距离 |
| 区间类 | 区间 [i, j] 上的结果 | 5 最长回文子串 |

三类的差别要认清。网格类的两个下标是同一种东西，都是位置。双序列类的两个下标分属两个字符串，各自独立。区间类的两个下标是同一个序列上的左右端点，一般要求 i 小于等于 j。

## 三个核心模板

### 网格类

```python
def gridTemplate(m, n):
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
    return dp[m][n]
```

状态是走到这个格子，转移是从上面和左面两个方向来，边界是第一行和第一列单独处理。62 和 64 用的都是这个骨架。

### 双序列类

```python
def twoSeqTemplate(s1, s2):
    m, n = len(s1), len(s2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i - 1] == s2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
```

状态是两个前缀，两个下标各自独立，都从小到大遍历。相等时取左上方，不等时取上面和左边。1143 和 72 用的是这个骨架，只是不相等时的处理不同。

### 区间类

```python
def intervalTemplate(s):
    n = len(s)
    dp = [[False] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = True
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j] and (length == 2 or dp[i + 1][j - 1]):
                dp[i][j] = True
    return dp
```

状态是区间 [i, j]，转移依赖更短的区间，所以外层要按区间长度遍历。单元素的区间要先初始化，它们是所有更长区间的基础。

## 遍历顺序怎么定

方法只有一条，先把 dp[i][j] 依赖哪些格子列出来，再让循环顺序保证那些格子更早算好。

网格类和双序列类依赖左上方、上方和左方，所以两层循环都从小到大就行。外层放 i 还是放 j 都可以。

区间类要特别注意。dp[i][j] 依赖的是比它短的区间，比如 dp[i+1][j-1] 的长度比它少 2。如果按左端点从小到大遍历，算 dp[i][j] 的时候 dp[i+1][j-1] 还没算，拿到的就是初值。所以区间类必须按长度遍历。

```python
for length in range(2, n + 1):
    for i in range(n - length + 1):
        j = i + length - 1
```

这两层循环的意思是把所有长度是 2 的区间先算完，再算长度是 3 的，以此类推。这是区间类独有的写法。

## Python 基础

### 二维数组必须用列表推导式

```python
dp = [[0] * (n + 1) for _ in range(m + 1)]   # 正确，每行是独立的列表
dp = [[0] * (n + 1)] * (m + 1)               # 错误，所有行指向同一个列表
```

浅拷贝这一行改一个位置会带着改所有行，而且不报错，是二维动态规划里最隐蔽的错误。

### 初值的方向

```python
dp = [[0] * n for _ in range(m)]                              # 求最大或者计数
dp = [[float('inf')] * n for _ in range(m)]                   # 求最小
```

规则和一维一样，只是要写进列表推导式里。注意求最小的题里，边界往往不能直接填正无穷，要单独初始化。

### 加一行一列

把数组开成 m 加 1 乘 n 加 1，让第 0 行和第 0 列承载边界情况，比如空串或者还没开始走。好处是转移式对所有格子统一，代码里少一堆特判。代价是要记住 dp 的下标比输入大 1，取字符要写成 s[i-1] 和 s[j-1]。

### 空间压缩

网格类的每一行只依赖上一行和本行的左边，所以可以只留一行，从左往右原地更新。

```python
dp = [0] * (n + 1)
for i in range(1, m + 1):
    for j in range(1, n + 1):
        dp[j] = dp[j] + dp[j - 1]
```

这里的 dp[j] 在更新前是上一行的值，dp[j-1] 是本行刚算出来的新值，正好对应上面加左边。从左往右是必须的。

双序列类也能压成一行，但要多存一个左上角的值，因为它会被当前位置覆盖。

## Hot 100 五道题

### 62. 不同路径

```python
def uniquePaths(m, n):
    dp = [[1] * n for _ in range(m)]   # 第一行和第一列都只有 1 条路

    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]

    return dp[m - 1][n - 1]
```

- 网格类最干净的一题。只能往右或者往下，所以走到某格的路只从上面和左边来
- 第一行只能一路往右走，第一列只能一路往下走，各自只有 1 条路，所以整表初始化为 1
- 返回 dp[m-1][n-1]，m 和 n 是尺寸，下标最大到 m 减 1 和 n 减 1
- 这张表的形状和杨辉三角一样，路径数也等于组合数 C(m+n-2, m-1)
- 可以压成一维，`dp[j] = dp[j] + dp[j - 1]` 从左往右更新
- 复杂度 O(m 乘 n) 时间，O(m 乘 n) 空间，压缩后 O(n)

### 64. 最小路径和

```python
def minPathSum(grid):
    m, n = len(grid), len(grid[0])
    dp = [[0] * n for _ in range(m)]
    dp[0][0] = grid[0][0]

    for j in range(1, n):
        dp[0][j] = dp[0][j - 1] + grid[0][j]
    for i in range(1, m):
        dp[i][0] = dp[i - 1][0] + grid[i][0]

    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]

    return dp[m - 1][n - 1]
```

- 和 62 骨架相同，差别是求最小而不是计数，而且每个格子带权重
- 转移要从上面和左边挑小的那个，再加当前格子的值。忘记加权重是最常见的错
- 第一行和第一列要一路累加，因为边界上的路径是唯一的
- 也可以直接在 grid 上原地改，额外空间降到 O(1)
- 复杂度 O(m 乘 n) 时间，O(m 乘 n) 空间，压缩后 O(n)

### 5. 最长回文子串

```python
def longestPalindrome(s):
    n = len(s)
    if n < 2:
        return s

    dp = [[False] * n for _ in range(n)]
    start, best = 0, 1

    for i in range(n):
        dp[i][i] = True

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j] and (length == 2 or dp[i + 1][j - 1]):
                dp[i][j] = True
                if length > best:
                    best = length
                    start = i

    return s[start:start + best]
```

- 区间类。状态是 s 从 i 到 j 这一段是不是回文，转移看两端是否相等、内部是否也是回文
- 遍历必须按区间长度，因为 dp[i][j] 依赖更短的区间 dp[i+1][j-1]
- 长度为 2 的情况要单独处理，去掉两端之后区间就空了
- 单字符区间全部初始化为 True，它们是所有更长区间的基础
- 答案不是某一个固定格子，要一边填表一边记下最长的长度和起点，最后用切片取出子串
- 易错：按左端点从小到大遍历。用 "aaaa" 一试就知道，正确长度是 4，那种写法会得到 3
- 复杂度 O(n^2) 时间，O(n^2) 空间。中心扩展法是 O(n^2) 时间和 O(1) 空间

### 1143. 最长公共子序列

```python
def longestCommonSubsequence(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    return dp[m][n]
```

- 双序列类的模板。状态是两个字符串各取前几个字符时的最长公共子序列长度
- 末位字符相等时可以配成一对，取左上方加 1
- 不相等时这两个字符不可能同时用上，要舍弃其中一个，取上面和左边的较大值。两个方向都要看
- 第 0 行和第 0 列全为 0，含义是空串和任何串的公共子序列长度都是 0
- 取字符要用 i-1 和 j-1，dp 的下标比字符串大 1
- 易错：把子序列当成子串。子串要求连续，那种情况下不相等时要直接清零，是另一道题
- 复杂度 O(m 乘 n) 时间，O(m 乘 n) 空间，压缩成一行后是 O(n)

### 72. 编辑距离

```python
def minDistance(word1, word2):
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j - 1], dp[i - 1][j], dp[i][j - 1])

    return dp[m][n]
```

- 双序列类里最完整的一题。状态是把 word1 的前 i 个字符变成 word2 的前 j 个字符的最少操作数
- 三种操作对应三个方向。替换是 dp[i-1][j-1]，删除是 dp[i-1][j]，插入是 dp[i][j-1]
- 删除对应 i 减 1，因为删掉的是 word1 的字符。插入对应 j 减 1，因为补上的是 word2 的字符
- 两个字符相等时不需要任何操作，直接取 dp[i-1][j-1]，不能加 1
- 边界是 dp[i][0] 等于 i 和 dp[0][j] 等于 j，分别表示删光和插满
- 易错：想用最长公共子序列的长度直接推答案。有替换操作之后那个公式不成立
- 复杂度 O(m 乘 n) 时间，O(m 乘 n) 空间，压缩成一行后是 O(n)

## 五题总表

| 题号 | 类型 | 状态定义 | 转移 | 时间 |
| --- | --- | --- | --- | --- |
| 62 不同路径 | 网格 | 走到格子 (i, j) 的路径数 | 上面加左边 | O(m 乘 n) |
| 64 最小路径和 | 网格 | 走到格子 (i, j) 的最小和 | 上面和左边取较小值再加权重 | O(m 乘 n) |
| 5 最长回文子串 | 区间 | 区间 [i, j] 是否回文 | 两端相等且内部回文 | O(n^2) |
| 1143 最长公共子序列 | 双序列 | 两个前缀的最长公共子序列长度 | 相等取左上角加 1，不等取两边最大值 | O(m 乘 n) |
| 72 编辑距离 | 双序列 | 两个前缀之间的最少操作数 | 相等取左上角，不等取三个方向最小值加 1 | O(m 乘 n) |

## 常见易错点

第一，状态定义说不清。两个下标分别代表什么必须能用一句话讲明白，讲不明白说明状态没定好。

第二，二维数组写成浅拷贝。`[[0] * n] * m` 会让所有行共用一份数据。

第三，遍历顺序错。最常见的是区间类没有按长度遍历，导致算 dp[i][j] 时用到的短区间还是初值。用 "aaaa" 能测出 5 的这个问题。

第四，边界没有单独初始化。网格类的第一行只能一路往右，第一列只能一路往下。双序列类里，1143 的第 0 行第 0 列全是 0，72 的第 0 行要填成 0 到 n、第 0 列要填成 0 到 m，两题含义不同。5 的单字符区间要先填成回文。

第五，下标错位。dp 加了第 0 行第 0 列之后，取字符要写成 s[i-1] 和 s[j-1]。

第六，答案位置取错。网格类返回 dp[m-1][n-1]，双序列类返回 dp[m][n]，区间类要取全表的最优值。

第七，空间压缩之后遍历方向反了。网格类压缩之后必须从左往右，双序列类压缩之后要多存一个左上角的值。

第八，和相邻的题混淆。子序列和子串是两回事，62 和 64 的转移只差一个 min，1143 和 72 的转移只差不相等时的处理。

## 共同规律

这五道题按类型分成三组，每组一个模板。

网格类，62 和 64。状态是走到某个格子，两个下标是同一种东西。转移是从上面和左边来，第一行和第一列单独处理。两题的区别只在转移的运算，一个计数一个求最小。

双序列类，1143 和 72。状态是两个字符串各取前缀，两个下标各自独立。都是两层循环从小到大，相等时看左上方。差别在不相等的时候，1143 求最长所以取两边最大值，72 求最少所以取三个方向最小值再加 1。

区间类，5。状态是一个区间的两端，转移依赖更短的区间，所以外层按区间长度遍历。单元素区间要先初始化。

做题的时候先判断属于哪一类，判断信号看题目在问什么。

- 问网格上的路径、代价、方案数，想网格类
- 问两个字符串的关系，想双序列类
- 问某个区间是否满足某种性质、区间上的最优值，想区间类

还有一句关于复杂度的经验。二维状态数是 m 乘 n，如果每个状态还要枚举一个切点或者一个选择，就要再乘一次，这类题的复杂度通常是 O(n^3)。

到这里 Hot 100 里就剩下技巧那一组了，题单是 136 只出现一次的数字、169 多数元素、75 颜色分类、31 下一个排列、287 寻找重复数。
