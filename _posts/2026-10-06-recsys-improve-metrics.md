## 0. 本章快速总结（一页版）

这章没有新模型，讲的是「怎么让推荐系统指标变好」——把前面章节学的技术当工具箱，在具体业务目标下怎么用。

**指标优先级**：最核心的是 DAU 和留存（LT7/LT30），其次使用时长、总阅读数、总曝光数；点击率、交互率反而只是非核心。UGC 平台额外看发布量和发布渗透率。所有涨指标手段最终服务于 DAU/留存/发布，而不是 CTR。

**涨指标的五个方向**

1. **改召回**：双塔三大改进（正负样本、网络结构如 DCN/多向量、训练方法）+ I2I 家族（U2I2I 是主流，ItemCF 和 Swing 都算 I2I）+ 小众通道（U2U2I、U2A2I 等）。核心操作：召回总量固定，往里加有效通道、调配额
2. **改排序**：精排最有效的是基座加深加宽、加新预估目标（评论率、关注率等）并融进排序分——MMoE 这类结构「往往无效」；粗排看点是粗精排一致性（精排当老师蒸馏粗排）；在线学习和老汤模型是迭代工程的两难——增量更新涨指标大但烧机器，老模型越训越强难超越
3. **提升多样性**：精排用「兴趣分 + 多样性分」排序并配打散规则；召回加噪声、抽样用户行为序列；留约 2% 流量做兴趣探索，短期伤指标、长期涨留存
4. **特殊对待特殊人群**：新用户/低活用户行为少，就少出广告、不做新物品探索、用特殊内容池保质量；模型可用大模型 + 残差小模型或 GBDT 校准；反面教材是每个人群维护一个大模型，长期没人维护反而更差
5. **利用三种交互行为**：关注（促关注提留存、帮低粉作者涨粉促发布、挖掘隐式关注）；转发（识别站外 KOL 做分享回流，别盲目提高所有人的转发权重）；评论（新物品缺评论就提权促发布、促评论提留存）

**一句话记忆**：这章 = 指标体系（DAU/留存/发布是老大）+ 五把扳手（召回、排序、多样性、特殊人群、关注转发评论），每把扳手都是对前面模型的业务向调整。

## 1. 评价指标总览

### 指标优先级

- **最核心指标：DAU（日活）和留存**
  - 工业界最常用 **LT7、LT30** 衡量留存：某用户今天登录，未来 7 天中有 4 天登录，则今天的 LT7 = 4
  - LT 增长通常意味着用户体验提升（除非 LT 增长同时 DAU 下降——例如禁止低活用户登录，DAU 会降、LT 会升）
- **其他核心指标**：用户使用时长、总阅读数（总点击数）、总曝光数，重要性低于 DAU 和留存
  - 时长增长，LT 通常会增长
  - 时长增长，阅读数、曝光数**可能下降**（用户看久了深度内容，刷的条数反而少）
- **非核心指标**：点击率、交互率等
- **UGC 平台**：发布量和发布渗透率也是核心指标

### 涨指标的方法（全章框架）

1. 改进召回模型、添加新的召回模型
2. 改进粗排和精排模型
3. 提升召回、粗排、精排中的多样性
4. 特殊对待新用户、低活用户等特殊人群
5. 利用关注、转发、评论这三种交互行为

## 2. 改进召回

### 召回通道、配额与内容池

- 推荐系统有几十条召回通道，**召回总量固定**：总量越大指标越好，但粗排计算量越大
- **双塔模型和 I2I（item-to-item）是最重要的两类召回模型**，占据大部分配额
- 有很多小众模型配额很少；总量不变的前提下，添加某些召回模型可以提升核心指标
- 有很多内容池（30 天物品、1 天物品、6 小时物品、新用户优质内容池、分人群内容池）；同一个模型可用于多个内容池，得到多条召回通道

### 改进双塔模型（三个方向）

**方向 1：优化正负样本**

- 简单正样本：有点击的 (用户, 物品) 二元组
- 简单负样本：随机组合的 (用户, 物品) 二元组
- 困难负样本：排序靠后的 (用户, 物品) 二元组

**方向 2：改进神经网络结构**

- Baseline：用户塔、物品塔分别是全连接网络，各输出一个向量
- 改进：用 DCN 代替全连接网络
- 改进：用户塔中使用用户行为序列（last-n）
- 改进：用**多向量模型**代替单向量模型（标准双塔也叫单向量模型，一个用户/物品用多个向量表示能表达多兴趣）

**方向 3：改进训练方法**

- Baseline：二分类，让模型学会区分正负样本
- 改进：二分类 + batch 内负采样（需要纠偏）
- 改进：自监督学习，让冷门物品的 embedding 学得更好

### Item-to-Item（I2I）

I2I 是一大类基于相似物品做召回的方法，最常见用法是 **U2I2I**：

```
用户 u 喜欢物品 i₁（历史上交互过的）→ 找 i₁ 的相似物品 i₂（I2I）→ 把 i₂ 推荐给 u
```

物品相似度怎么算？

- 方法 1：ItemCF 及其变体（一些用户同时喜欢 i₁、i₂ → 相似）。ItemCF、Online ItemCF、Swing、Online Swing 都是同一思想，线上可同时使用并各分配配额
- 方法 2：基于物品向量表征算相似度（双塔、图神经网络都能学物品向量）

### 小众召回模型

类似 I2I 的链路扩展：

- **U2U2I**（user → user → item）：相似用户喜欢的物品
- **U2A2I**（user → author → item）：喜欢的作者发布的物品
- **U2A2A2I**（user → author → author → item）：相似作者发布的物品

更复杂的模型：PDN（Path-based Deep Network）、Deep Retrieval、SINE（Sparse-Interest Network）、M2GRL（多任务多视图图表示学习）。

### 总结

- 双塔：优化正负样本、网络结构、训练方法
- I2I：同时用 ItemCF 变体和向量表征
- 添加小众模型（PDN、Deep Retrieval、SINE、M2GRL）
- 召回总量不变的前提下调整各通道配额（可以让各用户群体用不同配额）

## 3. 改进排序

### 精排模型的改进

精排 = 基座（离散 + 连续特征 → 向量）+ 多目标预估头。

**基座的改进**

1. 基座加宽加深：计算量更大、预测更准
2. 自动特征交叉：bilinear（FiBiNet）、LHUC 等
3. 特征工程：加统计特征、多模态内容特征

**多目标预估的改进**

1. **增加新的预估目标**并加入融合公式（最标准的目标：点击率、点赞率、收藏率、转发率、评论率、关注率、完播率；还可找更多目标，如进入评论区、给别人评论点赞）
2. MMoE、PLE 等结构可能有效，但**往往无效**
3. 纠正 position bias 可能有效，也可能无效

### 粗排模型的改进

- 粗排打分量比精排大 10 倍，模型必须快
- 简单模型：多向量双塔，同时预估多个目标
- 复杂模型：三塔模型（COLD）效果好，但工程实现难度较大

**粗精排一致性建模（蒸馏精排训练粗排）**

- 方法 1：**pointwise 蒸馏**——用精排预估当粗排拟合目标。例：用户有点击（y=1）、精排预估 p=0.6，用 0.8 作为粗排目标
- 方法 2：**pairwise/listwise 蒸馏**——按精排预估排序，用 learning to rank（LTR）让粗排拟合物品的序（而非值）；通常用 pairwise logistic loss
- 优点：粗精排一致性建模可以提升核心指标
- 缺点：如果精排有 bug、预估值有偏，会污染粗排训练数据

### 用户行为序列建模

- 最简单：物品向量取平均当用户特征（YouTube）
- DIN：注意力加权平均
- 工业界沿 **SIM 方向**发展：先用类目等属性筛选物品，再用 DIN 加权平均

三个改进方向：

1. **增加序列长度**：预测更准，但增加计算成本和推理时间
2. **改进筛选方法**：类目、物品向量聚类（离线多模态网络把物品聚成 1000 类，每个物品有聚类序号；线上候选物品聚类号是 70，就从百万序列里只保留聚类号为 70 的物品，可能只剩几千个）；多种筛选方法取并集
3. 对序列中的物品**使用 ID 以外的特征**

概括：让原始序列尽量长 → 筛选降低长度 → 筛选结果输入 DIN。

### 在线学习

- 既需要凌晨全量更新，也需要全天不间断增量更新
- 资源消耗巨大：假设一个精排模型的增量更新需要 10,000 CPU core，线上为做 AB 同时运行 m 个模型（1 个 holdout + 1 个推全 + m−2 个测试新模型），就需要 m 套在线学习机器
- 每套机器成本大，m 数量很小，制约模型开发迭代效率
- **在线学习对指标提升巨大，但会制约模型迭代升级效率**

### 老汤模型

用每天新数据对模型做 1 epoch 训练，久而久之老模型训练得非常好，很难被超过；新模型重新训练很难追上。

**问题 1：如何快速判断新模型结构是否优于老模型？**

不需要追平线上老模型，只比较结构：

- 新、老模型结构都随机初始化全连接层（embedding 层可随机初始化，也可复用老模型参数）
- 用同样的 n 天数据各训练 1 epoch（从旧到新）
- 新模型显著更优 → 结构很可能更好

**问题 2：如何更快追平、超过线上老模型？**

已初步判断新结构更优，用几十天数据训练新模型：

- 方法 1：尽可能复用老模型的 embedding 层（embedding 是对用户/物品特点的「记忆」，比全连接层学得慢）
- 方法 2：老模型当 teacher 蒸馏新模型（用 y = 老模型预测作为训练目标，混合真实行为）

## 4. 提升多样性

### 精排多样性

精排结合兴趣分数和多样性分数排序：

```
s_i：兴趣分数（融合多个预估目标）
d_i：多样性分数（物品 i 与已选中物品的差异）
排序分 = s_i + d_i
```

- 常用 MMR、DPP 算多样性分数
- **精排用滑动窗口，粗排不用**：精排决定最终曝光，曝光页面上邻近物品相似度应该小；粗排考虑整体多样性
- 除了多样性分数还有打散策略：类目打散（当前选中物品后 5 个位置不允许同二级类目）；多模态聚类打散（物品聚成 1000 类，当前物品后 10 个位置不允许同聚类）

### 粗排多样性

粗排给 5000 个物品打分，选出 500 个送精排：

- 先按兴趣分数 s 排序，取最高的 200 个直接送精排
- 剩余 4800 个按 s_i + d_i 排序，取最高的 300 个送精排

### 召回多样性

1. **双塔用户向量加噪声**：算出用户向量后、ANN 检索前加随机噪声；用户兴趣越窄（最近交互只覆盖少数类目）噪声越强，让召回更多样
2. **抽样用户行为序列**：保留最近 r 个物品，从剩余 n−r 个中随机抽 t 个（均匀或按类目平衡的非均匀抽样），用 r+t 个代替全部 n 个。效果：注入随机性 + n 可以非常大（用到很久以前的兴趣）
3. **U2I2I 抽样种子物品**：n 个交互物品类目少且不平衡（如 0.4n 是足球、0.2n 是电视剧），做非均匀抽样让类目平衡，覆盖类目更多
4. **探索流量**：每个用户曝光中留 2% 给非个性化推荐——维护精选内容池（交互率高的优质物品，可分人群），随机抽样几个物品跳过排序直接插入结果；短期负向影响核心指标，长期正向

## 5. 特殊对待特殊用户人群

### 为什么

1. 新用户、低活用户行为少，个性化推荐不准
2. 容易流失，要促使他们留存
3. 特殊用户行为（点击率、交互率）不同于主流用户，全量数据训练的模型在特殊人群上有偏

### 召回：构造特殊内容池

新用户、低活用户个性化不准 → **保证内容质量**。针对特定人群特点构造内容池（如喜欢评论的中年女性 → 促评论内容池）。

构造方法：

- 方法 1：按物品交互次数、交互率选优质物品——圈定人群，只用该人群对物品的交互数据打分，取最高分进池；内容池有弱个性化效果；定期更新（加新物品、淘汰交互率低和过时的老物品）；只对该人群生效
- 方法 2：因果推断，判断物品对人群留存的贡献，按贡献值选物品

召回用双塔模型从特殊池中检索。训练代价：正常用户无论多少内容池都只训练一个双塔；新用户历史交互少需单独训练。推理代价：特殊内容池比全量池小 10~100 倍，额外算力不大。

### 排序策略：保护特殊用户

- **排除低质量物品**：新用户/低活用户只关心留存，少出甚至不出广告；不在他们身上对新物品做探索（新笔记推荐不准会伤体验，探索只放在活跃老用户上并 boost）
- **差异化融分公式**：低活用户人均点击量小、没点击就没交互 → 提高点击率权重；保留几个坑位给点击率最高的物品（如 500 选 50，3 个坑位给 CTR 最高，剩余 47 个由融分公式决定），甚至把点击率最高物品排第一

### 排序模型：消除预估偏差

- 方法 1：**大模型 + 小模型**——大模型（全量数据）拟合用户行为 y，小模型（特殊用户数据）拟合残差 y−p；主流用户只用大模型预估 p，特殊用户用 p+q
- 方法 2：**融合多个 experts（类似 MMoE）**——只用一个模型，多个 experts 各输出向量，按用户特征算权重做加权平均
- 方法 3：**大模型预估后用 GBDT 校准**——把用户特征 + 大模型预估的点击率/交互率喂给小模型，在特殊人群数据上拟合真实行为

**错误的做法**：每个用户人群单独维护一个大模型。短期可涨指标，但维护代价大、长期有害——特殊人群模型很快过时（主模型迭代后 AUC 超过它），且长期无人维护；下线换成主模型反而提升 AUC。

## 6. 利用交互行为（关注、转发、评论）

交互行为最简单的用法：把交互率当作预估目标，融合进排序分。但关注、转发、评论还有更大的价值。

### 关注

**留存价值：促关注**

- 用户关注的作者越多，平台吸引力越强，留存率与关注作者数正相关
- 对关注数 f 较小的用户，促使他关注更多作者：
  - 方法 1：排序融分加 `w(f)·p_关注率`，w 是单调递减函数——f 小则 w 大，物品即使关注率一般也能拿到加分
  - 方法 2：构造促关注内容池（物品关注率高），f 小就用，配额可固定或与 f 负相关

**发布价值：帮低粉作者涨粉**

- UGC 平台核心指标是发布量/发布率，交互（尤其关注、评论）提升作者发布积极性
- 粉丝越少的作者，每增加一个粉丝对发布积极性提升越大
- 排序融分加 `w(f_a)·p_关注率`，w 随作者粉丝数单调递减，帮助低粉新作者涨粉

**隐式关注关系做召回**

- 显式关注：用户关注了作者（U2A2I，点击率/交互率通常高于其他通道）
- 隐式关注：用户喜欢看该作者内容但没关注；数量远大于显式关注，挖掘隐式关注可提升指标

### 转发（分享回流）

- A 平台用户把物品转发到 B 平台能吸引站外流量，促转发可提升 DAU 和消费指标
- 简单提高转发率权重（w·p_转发）能吸引流量，但负向影响点击率和其他交互率
- **KOL 建模**：在不损害点击和其他交互的前提下多吸引流量——识别其他平台的 KOL（判断依据：该用户历史转发带来的站外流量），给 KOL 用户多曝光他们可能转发的内容：
  - 方法 1：排序融分加 `k_u·p_转发率`（k_u 表示该用户是否为站外 KOL）
  - 方法 2：构造促转发内容池，只对站外 KOL 生效

### 评论

**促发布**：新物品评论少会打击作者积极性——排序融分加 `w_i·p_评论率`，w_i 与物品已有评论数负相关，让新物品尽快获得评论。

**留存价值**：

- 给喜欢讨论的用户促评论内容池，让他们更多参与讨论，利于留存
- 识别常留高质量评论的用户（评论点赞量高），用排序和召回策略鼓励他们多留评论——高质量评论对作者和其他用户留存都有贡献

## 复习速记

- 核心指标：DAU + 留存（LT7/LT30）；其次时长、阅读数、曝光数；CTR 等是非核心；UGC 平台发布量也是核心
- 涨指标五方向：召回 / 粗精排 / 多样性 / 特殊人群 / 关注转发评论
- 召回改进：双塔（样本、结构 DCN+last-n+多向量、训练方法）、I2I（ItemCF 变体 + 向量）、小众通道（U2U2I/U2A2I/PDN/Deep Retrieval 等）、总量不变调配额
- 精排改进：基座加深加宽/交叉/特征工程；加新目标往往比换 MMoE/PLE 结构更有效
- 粗排：三塔 COLD；蒸馏精排做粗精排一致（pointwise 蒸馏值 / LTR 蒸馏序），注意精排 bug 污染
