## 一句话概括

这一组没有统一套路，五道题各用一个独立的小技巧。共同点是代码短、结论出人意料，都要求在 O(n) 时间和 O(1) 额外空间内完成，考的是能不能想到那个关键性质。

## 这一组题用到的技巧

| 题号 | 技巧 | 一句话原理 |
| --- | --- | --- |
| 136 只出现一次的数字 | 异或 | 相同的数异或得 0，抵消掉之后只剩答案 |
| 169 多数元素 | 摩尔投票 | 不同的数两两抵消，多数元素一定能剩下 |
| 75 颜色分类 | 三指针分区 | 把数组切成四段，用三个指针维护边界 |

| 287 寻找重复数 | 把下标和值看成图 | 数组构成一条带环的路径，环的入口就是重复值 |

## 五个技巧的要点

### 异或

三条性质放在一起就能用。相同的两个数异或是 0，任何数和 0 异或是它自己，异或满足交换律和结合律。所以把数组全部异或起来，成对出现的数会抵消，剩下的就是答案。

```python
ans = 0
for x in nums:
    ans ^= x
```

判断信号是题目里出现「其他元素都出现两次」「只有一个出现一次」这类配对描述。

### 摩尔投票

维护一个候选值和一个计数器。遇到和候选相同的数计数加一，不同的数计数减一，计数归零时换候选。因为答案的数量超过一半，比其他所有元素加起来还多，所以抵消到最后一定剩下它。

```python
candidate, count = None, 0
for x in nums:
    if count == 0:
        candidate = x
    count += 1 if x == candidate else -1
```

题目不保证答案一定存在时，最后要再扫一遍验证候选的出现次数是否真的超过一半。

### 三指针分区

把数组分成四段，low 左边全是 0，low 到 mid 减 1 全是 1，mid 到 high 是未处理区，high 右边全是 2。每轮只看 nums[mid]，遇到 0 就和 low 交换，遇到 2 就和 high 交换，遇到 1 就跳过。

```python
low, mid, high = 0, 0, len(nums) - 1
while mid <= high:
    if nums[mid] == 0:
        nums[low], nums[mid] = nums[mid], nums[low]
        low += 1
        mid += 1
    elif nums[mid] == 1:
        mid += 1
    else:
        nums[mid], nums[high] = nums[high], nums[mid]
        high -= 1
```

和 high 交换之后 mid 不能动，因为换过来的数还没看过。

### 从右往左找转折点

只要题目关心最靠右的、最后一个满足条件的位置，就从右往左扫。下一个排列用这个动作找两个位置，先找最靠右的升序对，再找右边第一个比它大的数。

```python
i = len(nums) - 2
while i >= 0 and nums[i] >= nums[i + 1]:
    i -= 1
```

### 把下标和值看成图

当数组长度是 n 加 1 而值域是 1 到 n 时，把 f(i) 等于 nums[i] 看成一条边，从下标 0 出发就会走进一个环，环的入口就是重复的数。因为值不可能是 0，所以 0 没有入边，一定在环外，可以当起点。

```python
slow = fast = 0
while True:
    slow = nums[slow]
    fast = nums[nums[fast]]
    if slow == fast:
        break

slow = 0
while slow != fast:
    slow = nums[slow]
    fast = nums[fast]
```

这就是快慢指针找环入口的两阶段写法，和 142 环形链表完全一样。

## Python 基础

### 位运算速查

| 写法 | 作用 |
| --- | --- |
| `x ^ y` | 异或，两位相同得 0，不同得 1 |
| `x & y` | 按位与，两位都为 1 才得 1 |
| `x \| y` | 按位或，有一位为 1 就得 1 |
| `x & 1` | 取最低位，用来判断奇偶 |
| `x >> 1` | 右移一位，相当于整除 2 |
| `x << 1` | 左移一位，相当于乘 2 |
| `x & (x - 1)` | 去掉最低位的那个 1 |
| `x & (-x)` | 只保留最低位的那个 1 |

Python 的整数是任意精度的，负数用无限位补码的语义参与运算。异或的两条基本性质对负数同样成立，136 那题不需要额外处理。

### 原地交换和切片反转

```python
nums[i], nums[j] = nums[j], nums[i]   # 原地交换，不需要临时变量
nums[i + 1:] = reversed(nums[i + 1:]) # 原地反转一段
nums.reverse()                        # 原地反转整个列表
```

`reversed` 返回的是迭代器，赋值回切片是原地修改。`list.reverse()` 也是原地修改，而 `reversed(nums)` 不会改动原列表。

## Hot 100 五道题

### 136. 只出现一次的数字

```python
def singleNumber(nums):
    ans = 0
    for x in nums:
        ans ^= x
    return ans
```

- 其他元素都出现两次，异或之后两两抵消，剩下的就是只出现一次的那个
- ans 初值必须是 0，因为 0 是异或的单位元。写 1 或者 nums[0] 都会出错
- 用集合或者排序也能做，但空间是 O(n) 或者时间是 O(n log n)，不符合题目要求
- 变体一，其他元素都出现三次，要按位统计再对 3 取模
- 变体二，两个数各出现一次，先全部异或，再按最低位的 1 分组分别异或
- 复杂度 O(n) 时间，O(1) 空间

### 169. 多数元素

```python
def majorityElement(nums):
    candidate = None
    count = 0

    for x in nums:
        if count == 0:
            candidate = x
        if x == candidate:
            count += 1
        else:
            count -= 1

    return candidate
```

- 核心是抵消。每次拿一个多数元素抵消一个非多数元素，多数元素的数量比其他的总和还多，所以一定能剩下
- 必须先判断计数是否为 0 并切换候选，再拿当前数和候选比较，顺序反了会算错
- 题目保证多数元素一定存在，所以不用再验证一遍
- 和 136 可以对照记。136 抵消的是相同的数，用异或。169 抵消的是不同的数，用计数器
- 备选解法是排序后取中间元素，正确但是 O(n log n)
- 复杂度 O(n) 时间，O(1) 空间

### 75. 颜色分类

```python
def sortColors(nums):
    low, mid, high = 0, 0, len(nums) - 1

    while mid <= high:
        if nums[mid] == 0:
            nums[low], nums[mid] = nums[mid], nums[low]
            low += 1
            mid += 1
        elif nums[mid] == 1:
            mid += 1
        else:
            nums[mid], nums[high] = nums[high], nums[mid]
            high -= 1
```

- 循环不变量是四段区间，左边排好的 0，中间排好的 1，右边排好的 2，夹在中间的是未处理区
- 和 high 交换之后 mid 不能动，从右边换过来的数还没看过。这是这题最容易错的地方
- 循环条件必须是 mid 小于等于 high，两个指针重合时还有一个元素没处理
- 用 [1, 2, 0] 可以测出上面两个错误，正确答案是 0、1、2
- 备选解法是计数排序，两遍扫描，时间 O(n) 但要多扫一遍
- 复杂度 O(n) 时间，O(1) 空间

### 31. 下一个排列

```python
def nextPermutation(nums):
    n = len(nums)

    i = n - 2
    while i >= 0 and nums[i] >= nums[i + 1]:
        i -= 1

    if i >= 0:
        j = n - 1
        while nums[j] <= nums[i]:
            j -= 1
        nums[i], nums[j] = nums[j], nums[i]

    nums[i + 1:] = reversed(nums[i + 1:])
```

- 目标是比当前大的排列里最小的那个，所以改动位置尽量靠右，后缀尽量小
- 第一步找最靠右的升序对，第二步在右边找刚好比它大的数，第三步交换后把右边反转
- i 右边那一段原本是降序的，反转之后变成升序，正好是最小的后缀
- 最后一行不用加判断。i 等于负一时切片是整个数组，反转正好处理整个数组降序的情况
- 比较必须严格，第一步写 `>=`，第二步写 `<=`。写成严格大于或者严格小于都会在重复元素上出错
- 易错：用 [1, 2, 2] 能测出第一步写错，用 [2, 3, 2] 能测出第二步写错
- 复杂度 O(n) 时间，O(1) 空间

### 287. 寻找重复数

```python
def findDuplicate(nums):
    slow = fast = 0

    while True:
        slow = nums[slow]
        fast = nums[nums[fast]]
        if slow == fast:
            break

    slow = 0
    while slow != fast:
        slow = nums[slow]
        fast = nums[fast]

    return slow
```

- 数组长度是 n 加 1，值域是 1 到 n，所以把下标和值看成边之后一定会形成环
- 重复的那个数至少被两个下标指向，所以它就是环的入口
- 值不可能是 0，所以 0 没有入边，一定在环外，可以作为第二阶段的起点
- 第二阶段两个指针都每次走一步，这一点和 142 环形链表找入口完全一样
- 易错：用集合或者排序，违反常数额外空间或者不能修改数组的要求
- 备选解法是二分答案，统计小于等于 mid 的个数，时间 O(n log n)，空间 O(1)
- 复杂度 O(n) 时间，O(1) 空间

## 常见易错点

第一，看漏题目的前提条件。136 的异或要求其他元素恰好出现两次，改成三次就完全不能这么做。169 的摩尔投票要求多数元素一定存在，不保证的话要再验证一遍。

第二，把关键性质的适用条件放宽。287 的快慢指针要求值域恰好是 1 到 n，如果值域变了，映射关系就变了。

第三，指针更新写错。75 里和右边交换之后 mid 不能动，31 里两个比较符号必须是大于等于和小于等于，这几处错了代码都不报错，结果不对。

第四，忘记处理退化情况。31 里整个数组降序时 i 会变成负一，75 里 mid 和 high 重合时还要再处理一个元素。

第五，用更简单的解法但违反了约束。136 和 287 都能用哈希表做对，但题目要求的空间是 O(1)。287 还能靠原地排序做，但题目要求不能修改数组。

第六，只靠代码检查正确性。这一组的代码都很短，看不出思路对不对，一定要拿小例子手推，特别是只有一个或两个元素的情况。

## 共同规律

这一组五道题彼此之间没有共同的骨架，各自用一个独立的技巧。放在一起的价值在于，它们都是同一类题，要求在 O(n) 时间和 O(1) 额外空间内完成，都不能靠额外的数据结构帮忙。

正因为不能开额外的空间，每一步的操作必须本身就有信息量。异或把成对的数抹掉，摩尔投票把不同的数抵消，三指针靠交换把元素送到正确的位置，下一个排列靠交换和反转调整顺序，快慢指针靠两条不同速度的路径找到交点。这个共同点比代码形状更值得记住。

判断信号可以按下面这些来认。

- 题目说其他元素都出现两次，只有一个出现一次，想异或
- 题目说某个元素出现次数超过一半，想摩尔投票
- 题目里只有几种取值，要求原地排序并且只用一遍扫描，想多指针分区
- 题目问下一个排列、下一个更大的排列、字典序，想从右往左找转折点
- 题目给 n 加 1 个数、值域是 1 到 n、要求不改数组且常数空间，想快慢指针找环
