## 一句话概括

矩阵题的思路一般不难，难在把下标和边界写对。这一组的共性就是在二维下标上做文章，用坐标变换、边界收缩或者方向排除来减少工作量。

## 怎么选工具

- 要原地记住某些行和列的状态 → 借用第一行第一列当标记板
- 按固定顺序走格子 → 四条边界往里收缩
- 元素之间有固定的位置对应 → 坐标变换，或者四个位置一起轮换
- 行列各自有序 → 从右上角或左下角出发，每次排除一行或一列

## Python 基础：矩阵操作速查

### 行列和下标的写法

```python
m = len(matrix)        # 行数
n = len(matrix[0])     # 列数
matrix[r][c]           # r 是行，c 是列
matrix[r]              # 一整个行列表
```

### 创建矩阵的坑

```python
bad = [[0] * 3] * 2                  # 两行共享同一份数据，改一行两行都变
good = [[0] * n for _ in range(m)]   # 每行独立
```

### 方向数组和边界判断

```python
dirs = [(0, 1), (1, 0), (0, -1), (-1, 0)]   # 右 下 左 上
d = (d + 1) % 4                              # 顺时针转向

if 0 <= r < m and 0 <= c < n:                # 边界检查
```

Python 里下标 `-1` 表示最后一个元素，不会报错，所以漏写 `r >= 0` 这种检查只会读到错误数据，很难排查。

### 转置和翻转

```python
# 原地转置，内层从 i+1 开始，只处理对角线上方那一半
for i in range(m):
    for j in range(i + 1, n):
        matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

# 便捷转置，返回新数据
transposed = [list(row) for row in zip(*matrix)]

# 水平翻转，每行左右颠倒
for row in matrix:
    row.reverse()

# 垂直翻转，行的顺序颠倒
matrix.reverse()
```

### 旋转的拼装

```python
(i, j) → 转置 → (j, i) → 每行左右翻转 → (j, n - 1 - i)
```

最后这个式子就是顺时针 90 度的映射。由此可以得到三条规律。

- 顺时针 90 度 = 转置 + 每行左右翻转
- 逆时针 90 度 = 转置 + 行的顺序颠倒
- 旋转 180 度 = 每行左右翻转 + 行的顺序颠倒

## Hot 100 四道题

### 73. 矩阵置零 —— 原地标记

```python
def setZeroes(matrix):
    m, n = len(matrix), len(matrix[0])

    first_row_zero = any(matrix[0][j] == 0 for j in range(n))
    first_col_zero = any(matrix[i][0] == 0 for i in range(m))

    # 用第一行第一列当标记板
    for i in range(1, m):
        for j in range(1, n):
            if matrix[i][j] == 0:
                matrix[i][0] = 0
                matrix[0][j] = 0

    # 根据标记清空内部
    for i in range(1, m):
        for j in range(1, n):
            if matrix[i][0] == 0 or matrix[0][j] == 0:
                matrix[i][j] = 0

    # 最后处理第一行和第一列
    if first_row_zero:
        for j in range(n):
            matrix[0][j] = 0
    if first_col_zero:
        for i in range(m):
            matrix[i][0] = 0
```

- 用两个集合记录是 O(m + n) 空间，改成借第一行第一列存标记就降到 O(1)
- 第一行第一列自己也要被清空，所以用两个布尔变量单独存它们的状态
- 顺序固定，先记录边界状态，再用边界当标记板，最后处理边界
- 易错：两个布尔变量必须在标记之前算出来；内部遍历从下标 1 开始；清空时用 `or`；第一行第一列放到最后处理

### 54. 螺旋矩阵 —— 边界收缩

```python
def spiralOrder(matrix):
    if not matrix or not matrix[0]:
        return []

    m, n = len(matrix), len(matrix[0])
    top, bottom = 0, m - 1
    left, right = 0, n - 1
    res = []

    while top <= bottom and left <= right:
        for j in range(left, right + 1):          # 上边，从左到右
            res.append(matrix[top][j])
        top += 1

        for i in range(top, bottom + 1):          # 右边，从上到下
            res.append(matrix[i][right])
        right -= 1

        if top <= bottom:                         # 下边，从右到左
            for j in range(right, left - 1, -1):
                res.append(matrix[bottom][j])
            bottom -= 1

        if left <= right:                         # 左边，从下到上
            for i in range(bottom, top - 1, -1):
                res.append(matrix[i][left])
            left += 1

    return res
```

- 每走一条边就收一条边界，走过的地方自动被排除，不需要访问标记
- 每段遍历的起点要用收缩后的边界，否则角上的元素会被取两次
- 易错：`if top <= bottom` 和 `if left <= right` 不能省。单行时下面一行会重复读，单列时左边一列会重复读
- 另一种写法是方向数组加 `seen` 标记，逻辑更直白，但要多花 O(m × n) 空间

### 48. 旋转图像 —— 坐标变换

```python
def rotate(matrix):
    n = len(matrix)

    # 转置
    for i in range(n):
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

    # 每行左右翻转
    for i in range(n):
        matrix[i].reverse()
```

- 坐标映射是 `(i, j) → (j, n - 1 - i)`
- 把旋转拆成转置加翻转，两段各自都简单，不容易写错
- 一步到位的写法是找同一环上的四个位置一起轮换，用临时变量保证不丢数据

```python
n = len(matrix)
for i in range(n // 2):
    for j in range(i, n - 1 - i):
        temp = matrix[i][j]
        matrix[i][j] = matrix[n - 1 - j][i]
        matrix[n - 1 - j][i] = matrix[n - 1 - i][n - 1 - j]
        matrix[n - 1 - i][n - 1 - j] = matrix[j][n - 1 - i]
        matrix[j][n - 1 - i] = temp
```

- 易错：转置的内层要从 `i + 1` 开始，从 0 开始会换两次等于没换；`matrix[i] = matrix[i][::-1]` 不是原地修改，要用 `reverse()`

### 240. 搜索二维矩阵 II —— 从角出发排除

```python
def searchMatrix(matrix, target):
    if not matrix or not matrix[0]:
        return False

    m, n = len(matrix), len(matrix[0])
    i, j = 0, n - 1          # 从右上角出发

    while i < m and j >= 0:
        if matrix[i][j] == target:
            return True
        elif matrix[i][j] > target:
            j -= 1           # 这一列都太大，排除整列
        else:
            i += 1           # 这一行都太小，排除整行

    return False
```

- 右上角是这一行最大的数，也是这一列最小的数，所以比较之后方向唯一
- 比 target 大就排除整列，往左走；比 target 小就排除整行，往下走
- 左上角和右下角不能用，因为比较结果指向两个方向，无法决定走哪边
- 易错：循环条件两个都要写，`i` 只增不减，`j` 只减不增；这题不是全局有序，不能直接整体二分

## 四题对比

| 题号 | 问什么 | 套路 | 时间 | 额外空间 |
| --- | --- | --- | --- | --- |
| 73 | 把 0 所在的行列清空 | 原地标记 | O(m × n) | O(1) |
| 54 | 按螺旋顺序读元素 | 边界收缩 | O(m × n) | O(1) |
| 48 | 原地顺时针旋转 90 度 | 坐标变换 | O(n²) | O(1) |
| 240 | 在行列有序的矩阵里查找 | 从角出发排除 | O(m + n) | O(1) |

## 容易混的两个点

**74 和 240 不是一类。** 74 的条件是每行有序，并且下一行的第一个数大于上一行的最后一个数，把矩阵按行接起来就是整体升序，做一次二分就够。240 只有行内和列内有序，接起来不是有序数组，只能用从角出发的走法。

**方向和下标混用。** 几行遍历用 `i`，几列遍历用 `j`，从第一题就固定这个习惯。矩阵题写错的下标用肉眼看很难发现，靠习惯能省很多排查时间。

## 共同规律

四题都围绕「二维下标」做文章，只是角度不同。

- 73 把标记藏进第一行第一列，用数据自己存状态
- 54 用四条边界描述走过的范围，让走过的区域自动失效
- 48 把旋转拆成转置和翻转两个简单操作，避免直接搬元素时互相覆盖
- 240 找到右上角这个分界位置，让每一步都能确定唯一的搜索方向

写矩阵题时，先花一分钟把行列下标的含义和边界写清楚，再动手写循环。这一步做扎实，后面基本不会出错。
