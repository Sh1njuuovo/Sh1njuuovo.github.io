用户最近对物品的点击、点赞、收藏、转发等行为都是推荐系统中重要的特征，可以帮助召回和排序变得更精准。一般称这些用户的行为序列为 **LastN**，表示用户最近交互过 n 个物品。本篇记录对用户行为序列建模的方法，重点关注用户特征中的 LastN 行为序列，建模路线是：简单平均 → 注意力（DIN）→ 长序列 + 快速查找（SIM）。

---

## 1. 用户行为序列建模（LastN 特征）

最简单的建模方式是对用户行为取**简单平均**，作为特征输入召回、排序模型。

### LastN 特征

LastN 可以反映用户过去一段时间内对物品的兴趣，主要思想：

1. **LastN**：用户最近 n 次交互（点击、点赞等）的物品 ID
2. 对物品 ID 做 embedding，得到 n 个向量
3. 把 n 个向量取平均，作为用户的一种特征
4. **适用于召回双塔模型、粗排三塔模型、精排模型**

参考文献：Covington et al.（YouTube 深度学习推荐）, RecSys 2016。

### 小红书的实践

简单平均把不同行为混在一起。小红书将点击、点赞等交互行为的 LastN **分开**做 embedding，对每一类分别求平均，得到多个 LastN 特征，最后拼接起来输入召回或排序模型：

```
点击的 LastN → embedding → 平均 → 向量 1
点赞的 LastN → embedding → 平均 → 向量 2
收藏的 LastN → embedding → 平均 → 向量 3
              ↓ 拼接
          用户行为特征
```

工程上的两个补充：

- 对 embedding 向量求平均很常用，但实际效果更好的是 **attention**，代价是计算量更大
- 实际应用时，也会把物品的其他特征与物品 ID 的 embedding **拼接**后再输入

## 2. DIN 模型（注意力机制）

### DIN 模型

DIN 是对 LastN 序列建模的一种方法，用**加权平均**代替平均，本质是注意力机制（attention），权重即候选物品与用户 LastN 物品的相似度。基本思想：

1. 设候选物品向量为 q，用户 LastN 物品向量为 x₁...x_n
2. 对候选物品，计算它与每个 LastN 物品的相似度 α_i
3. 以相似度为权重，求 LastN 物品向量的加权和，结果是一个向量
4. 把得到的向量作为一种用户特征，输入排序模型，预估 (用户, 候选物品) 的点击率、点赞率等指标

从注意力角度看：把用户 LastN 物品向量作为注意力机制中的 **key 和 value**、候选物品向量作为 **query**，输入单头注意力层，就能得到与 DIN 一致的效果。

### DIN 为什么有效

简单平均的问题：用户兴趣多样（美妆、美食、汽车都看过），历史里各种兴趣取平均，每个兴趣都被稀释。

- 候选物品是**美食**：注意力让历史中美食相关的物品权重高，美妆、汽车相关的权重接近 0
- 候选物品换成**新闻**：注意力重点跟着候选物品转移到新闻相关的历史上

简单平均是「一个固定向量描述所有兴趣」，DIN 是「针对每个候选物品动态提取相关兴趣」，平均是静态的、注意力随候选物品变化。

### 简单平均 vs 注意力机制

| | 简单平均 | 注意力机制 |
| --- | --- | --- |
| 适用模型 | 双塔模型、三塔模型、精排模型 | 只适用精排模型，不适用双塔模型和三塔模型 |
| 原因 | 简单平均只需要用到 LastN，属于用户自身的特征，只需把 LastN 的平均向量作为用户塔输入 | 注意力机制需要用到 LastN 和候选物品；用户塔看不到候选物品，无法把注意力机制用在用户塔 |

## 3. SIM 模型（长序列建模）

SIM 是为了解决 DIN 的缺点而诞生的，主要目的是**保留用户的长期兴趣**。

### DIN 的缺点与改进

DIN 做注意力层计算时，计算量正比于用户行为序列长度 n。为防止计算量过大，只能记录最近几百个物品，于是 DIN 只关注**短期兴趣**、遗忘**长期兴趣**。而实践中长序列（长期兴趣）的效果优于短序列（短期兴趣）。

改进思路：

1. DIN 对 LastN 向量做加权平均，权重是相似度
2. 如果某 LastN 物品与候选物品差异很大，权重会接近零，对结果几乎没有贡献
3. 可以快速排除掉与候选物品无关的 LastN 物品，降低注意力层的计算量

这个改进思路就是 SIM 模型，工业实践中有效。

### SIM 模型

基本思想：

1. 保留用户长期行为记录，n 的大小可以是几千
2. 对每个候选物品，在用户 LastN 记录中做**快速查找**，找到 k 个相似物品
3. 把 LastN 变成 **TopK**，再输入注意力层
4. 计算量从 O(n) 降到 O(k)

### 第一步：查找

| 方法 | Hard Search | Soft Search |
| --- | --- | --- |
| 基本思想 | 根据候选物品的**类目**，保留 LastN 中类目相同的物品 | 对物品做 embedding 变成向量；候选物品向量作为 query，做（近似）k 近邻查找，保留 LastN 中最接近的 k 个 |
| 特点 | 简单、快速、无需训练 | 效果更好，编程实现更复杂 |

具体用哪种方法，根据工业实际应用的硬件/基建条件选择。

### 第二步：注意力机制 + 时间信息

SIM 的注意力结构跟 DIN 一致，只是输入从 LastN 向量换成 TopK 向量。区别在于 SIM 使用了**时间信息**：

1. 设用户与某个 LastN 物品的交互时刻距今为 δ
2. 对 δ 做离散化，再做 embedding，变成时间向量 d
3. 把物品 embedding 向量 x 与时间向量 d 做 concatenation，共同表征这个 LastN 物品

为什么 SIM 需要时间信息？因为：

- DIN 序列短，记录用户近期行为，时间影响小
- SIM 序列长，记录用户**长期**行为
- 时间越久远，对当前兴趣的重要性越低

所以作为记录长期兴趣的模型，SIM 有必要考虑时间对特征的影响。

### SIM 的结论

1. 长序列（长期兴趣）优于短序列（近期兴趣）
2. 注意力机制优于简单平均
3. Soft search 还是 Hard search，取决于工程基建
4. 使用时间信息有提升

参考文献：Qi et al., *Search-based User Interest Modeling with Lifelong Sequential Behavior Data*, CIKM 2020。

## 4. 本章小结

本篇记录对用户行为序列的建模方法，核心是对用户 **LastN 物品特征** 的应用。

最常用的方法是对 LastN 物品的 embedding 向量**求平均**，可以作为用户特征用于召回和排序。

**DIN** 用加权平均代替简单平均，本质是注意力机制：计算候选物品向量与用户 LastN 物品向量的相似度得到权重，再按权重求加权平均得到用户特征。也可以把 LastN 物品向量看成 key 和 value、候选物品向量看成 query 输入注意力层，效果一致。但注意力需要考察候选物品，无法在用户塔中实现，所以 DIN 只适用于精排。

由于注意力计算复杂度高，DIN 只能记录最近几百个物品，存在关注短期兴趣、遗忘长期兴趣的缺点。**SIM** 保留用户的长期兴趣：先对长序列做快速查找（Hard/Soft Search）筛出 TopK 向量，再把 TopK 输入注意力层，让 DIN 可以用于长序列。SIM 的注意力环节还加入了时间信息——将时间 embedding 与物品向量拼接，考虑时间久远对兴趣的影响，取得更好的效果。

## 复习速记

- LastN：最近 n 次交互的物品 ID → embedding → 平均向量当用户特征；召回双塔/粗排三塔/精排都能用
- 小红书实践：点击、点赞、收藏的 LastN 分开取平均再拼接；实际还会把物品其他特征和 ID embedding 拼接
- DIN：注意力（加权平均）替代平均；LastN 是 key/value、候选物品是 query，本质是单头注意力
- DIN 为什么有效：平均会稀释多样兴趣，注意力按候选物品动态加权，只突出相关兴趣
- DIN 适用性：只适用精排——需要候选物品参与，用户塔看不到候选物品
- SIM：DIN 只能记短期、算力 O(n) → 先快速查找 TopK（Hard 按类目 / Soft 按向量近邻）再注意力，算力降到 O(k)
- SIM 加时间 embedding：长序列里时间越久远重要性越低
- 结论记忆：长序列 > 短序列；注意力 > 简单平均；时间信息有提升
