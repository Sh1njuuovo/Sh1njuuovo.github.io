重排是对精排结果的顺序进行**再次微调**：一方面为了实现全局视角的最优排序，另一方面为了满足特定业务诉求和提升用户体验。实际上重排是对推荐系统中**多样性**的考察，多样性更能体现用户的个性化。多样性做得好，可以显著提升推荐系统的核心业务指标。

链路回顾：召回 → 粗排 →（后处理）→ 精排 →（后处理）→ 展示。粗排和精排用多目标模型对物品做 **pointwise 打分**（每个物品独立打分），重排则是从 n 个候选中选出 k 个的**子集选择**问题。

---

## 1. 推荐系统中的多样性

### 物品相似性的度量

做多样性前，先要度量「两个物品像不像」，主要有两类方法。

**方法一：基于物品属性标签**

- 物品属性标签：类目、品牌、关键词等
- 按一级类目、二级类目、品牌分别算相似度。例如：
  - 物品 i：美妆、彩妆、香奈儿
  - 物品 j：美妆、香水、香奈儿
  - 相似度：一级类目 1、二级类目 0、品牌 1
- 对三个相似度求**加权和**得到物品相似度，权重由人为设定

**方法二：基于物品向量表征**

- 前文介绍过召回双塔的物品塔能学出物品向量并算相似度，但由于长尾数据问题，这种方法实际效果**并不好**
- 一般更多用**基于内容的向量表征**。小红书的笔记是文字 + 图片的组合，图文相关性较高。以单图笔记为例：用 CNN 把图片变成向量，用 BERT 把文字变成向量，两个向量拼接起来就是这篇图文笔记的向量表征，可输入后续任务

CNN/BERT 怎么训练？通用数据训练的模型不一定贴合小红书的内容场景，人工标注数据成本又太大，所以 **CLIP** 是当前公认最有效的预训练方法：

1. 思想：对「图片—文本」二元组，预测图文是否匹配
2. 正负样本：来自同一篇笔记的图文作为正样本，来自不同笔记的图文作为负样本（batch 内负样本）
3. 优势：无需人工标注；小红书笔记天然包含图片和文字，大部分图文相关

参考文献：Radford et al., *CLIP*, ICML 2021。

### 提升多样性的方法

推荐系统希望提高曝光物品的多样性，也就是尽量让物品之间两两不相似。粗排和精排之后都需要后处理：

1. 粗排和精排用多目标模型对物品做 pointwise 打分。对物品 i，模型输出点击率、交互率等的预估，融合成分数 reward_i。reward_i 表示用户对物品的兴趣，即物品本身的价值
2. 给定 n 个候选物品（排序模型打分 reward₁...reward_n），后处理从中选出 k 个：**既要总分高，也要有多样性**

精排之后的后处理就是**重排**；粗排之后一般也存在后处理，不可忽视。后处理提升多样性，有利于业务指标增长。

## 2. MMR 多样性算法

Maximal Marginal Relevance（MMR）最早来自搜索排序，用相关性做排序。要解决的问题：

1. 精排给 n 个候选打分，融合后分数为 reward₁...reward_n
2. 物品 i、j 的相似度记作 sim(i,j)
3. 从 n 个中选出 k 个曝光，要求精排分数高、有多样性

### MMR 公式

记已选中的物品集合为 S、未选中的为 R。R 中每个物品 i 的 Marginal Relevance 分数：

```
MR_i = θ·reward_i − (1−θ)·max_{j∈S} sim(i,j)
```

- 第一项是物品 i 自身的精排分数（价值）
- 第二项是 i 与已选集合 S 中物品的最大相似度（多样性惩罚，越像越扣分）
- θ 是超参数，调整精排分数与多样性的权重占比

### MMR 算法流程

1. S 初始化为空集，R 初始化为全集 {1,...,n}
2. 选择精排分数 reward 最高的物品，从 R 移到 S
3. 再做 k−1 轮循环：
   a. 计算 R 中所有物品的 MR 分数
   b. 选出分数最高的物品，从 R 移到 S

### 滑动窗口

标准 MMR 在实际应用中有问题：

1. 已选中的物品越多（S 越大），越难找到与 S 中物品都不相似的物品
2. 设 sim 取值范围 [0,1]，当 S 很大时，`max sim` 几乎总是约等于 1，多样性惩罚项失效

解决方案：设置**滑动窗口 W**（比如最近选中的 10 个物品），用 W 代替公式中的 S：

```
argmax_{i∈R} θ·reward_i − (1−θ)·max_{j∈W} sim(i,j)
```

工业界滑动窗口非常常用，实践中效果更优，且有直观解释：给用户曝光的物品应当两两不相似，但**没必要让第 30 个物品与第 1 个物品不相似**——用户看到第 30 个时大概率已经忘了第 1 个。换言之，离得远的物品可以相似，不影响体验；离得近的物品必须差异大，否则用户能感知到缺乏多样性。

## 3. 业务规则约束下的多样性算法

工业应用为保护用户体验会设定很多业务规则，重排必须满足这些规则。小红书典型例子：

| 规则 | 规则说明 |
| --- | --- |
| 最多连续出现 k 篇某种笔记 | 物品分图文、视频；最多连续出现 k 篇图文、k 篇视频。如果第 i 到 i+k 都是图文，第 i+k+1 必须是视频 |
| 每 k 篇笔记最多出现 1 篇某种笔记 | 运营推广笔记的精排分会乘 >1 的系数（boost）获得更多曝光；为防止影响体验，限制每 k 篇最多 1 篇运营推广。如果第 i 位是运营推广，第 i+1 到 i+k−1 都不能是 |
| 前 t 篇笔记最多出现 k 篇某种笔记 | 前 t 篇最容易被看到、对体验最重要（小红书 top 4 为首屏）；带电商卡片的笔记过多影响体验，前 t 篇最多出现 k 篇 |

### MMR + 重排规则

在**满足规则的前提下**最大化 MR：

1. 每轮先用规则排除 R 中的部分物品，得到子集 R′
2. 把 MMR 公式中的 R 替换成 R′：

```
argmax_{i∈R′} θ·reward_i − (1−θ)·max_{j∈W} sim(i,j)
```

这样选中的物品天然符合规则。

## 4. DPP 多样性算法

行列式点过程（Determinantal Point Process, DPP）是一种经典的机器学习方法，目标是从一个集合中选出多样化的物品，与重排目标契合，是目前推荐系统重排中公认效果最好的多样性方法之一。

### 数学基础：超平行体

- 二维、三维空间中的超平行体就是平行四边形、平行六面体
- 一般定义：在 d 维空间中，一组向量 v₁...v_k 确定一个 k 维超平行体：

```
P(v₁,...,v_k) = {α₁v₁ + ... + α_k v_k | 0 ≤ α₁,...,α_k ≤ 1}
```

- 要求 k ≤ d（例如 3 维空间中可以有 2 维平行四边形）
- 求面积/体积用**施密特（Schmidt）正交化**思想：把不正交的向量组转化为正交向量组，面积 = 底 × 高（高由正交化得到），再逐维推广

什么时候体积最大/最小？设三个向量都是单位向量：

- 三个向量**正交**时，平行六面体为正方体，体积最大化 vol = 1
- 三个向量**线性相关**（落在同一平面）时，体积最小化 vol = 0

### 用体积衡量多样性

1. 给定 k 个物品，表征为单位向量 v₁...v_k（∈ R^d，d ≥ k）
2. 用超平行体的体积衡量多样性，体积介于 0 和 1 之间
3. 向量两两正交（多样性好）→ 体积最大化 vol = 1
4. 向量线性相关（多样性差）→ 体积最小化 vol = 0

实际计算时：

1. 把 k 个向量作为矩阵 V（d×k）的列
2. 设行列式与体积满足：

```
det(VᵀV) = vol²(P(v₁,...,v_k))
```

3. 因此用行列式 det(VᵀV) 衡量向量的多样性

> 2 维验证（个人推导）：两个列向量 v₁、v₂ 夹角为 φ，平行四边形以 v₁ 为底，高 = v₂ 减去其在 v₁ 上的投影（正交化），面积 = |v₁|·|正交化后的 v₂|。行列式那边 det(VᵀV) 展开整理后得到 |v₁|²|v₂|²sin²φ = 面积²。两边相等，证毕。

### 多样性问题

设 n 个物品的向量表征为 v₁...v_n，精排打分 reward₁...reward_n。从 n 个中选出 k 个组成集合 S，要求：

- **价值大**：`Σ_{i∈S} reward_i` 越大越好
- **多样性好**：S 中 k 个向量组成的超平行体体积越大越好

把 S 中 k 个向量组成矩阵 V_S（d×k），由 `det(V_SᵀV_S) = vol²` 可知行列式等价于体积，所以实际用行列式衡量多样性。

### 行列式点过程

DPP 求使行列式对数最大化的集合 S；Hulu 论文把 DPP 应用到推荐系统：

```
argmax_{S: |S|=k}  θ·Σ_{i∈S} reward_i + (1−θ)·log det(V_SᵀV_S)
```

设 A 是 n×n 矩阵，元素 a_ij = ⟨v_i, v_j⟩；给定向量需要 O(n d²) 时间计算 A。A_S 是 A 的一个 k×k 子矩阵（i,j ∈ S），替换后公式写作：

```
argmax_{S: |S|=k}  θ·Σ_{i∈S} reward_i + (1−θ)·log det A_S
```

DPP 是组合优化问题，用**贪心算法**求解（S 已选、R 未选）：

```
argmax_{j∈R} θ·reward_j + (1−θ)·log det A_{S∪{j}}
```

直观理解：给集合 S 添加新物品 j，等于在 A_S 的基础上**添加一行一列**。我们希望添加后行列式尽量大，也就是 j 不能与 S 中已有物品相似，否则行列式会接近 0。

### 复杂度：暴力 vs Hulu 快速算法

系统留给多样性算法的时间非常有限（10 毫秒左右），暴力计算行列式代价太大：

1. 对单个 j，计算 A_{S∪{j}} 的行列式需要 O(|S|³) 时间
2. 对 R 中所有 j，需要 O(|S|³·|R|) 时间
3. 要选出 k 个物品需循环 k 次，暴力总复杂度约 O(n·k⁴)（再算上构建 A 的 O(n d²)）

Hulu 论文的主要贡献是提出**快速数值算法**：利用 **Cholesky 分解**，大幅降低计算行列式的开销：

1. 分解 `A_S = L·Lᵀ`，L 是下三角矩阵（对角线以上元素全为 0）
2. 下三角矩阵的行列式等于对角线元素乘积，所以 `det A_S = det(L)² = Π l_jj²`
3. 每一轮循环，基于上一轮的 A_S = LLᵀ，可以快速求出所有 A_{S∪{j}} 的 Cholesky 分解，从而快速算出所有候选的 log det

最终仅需约 O(n·k³) 级别的时间就能从 n 个物品中选出 k 个，让 DPP 能落地线上。

参考文献：Chen et al., *Fast Greedy MAP Inference for DPP*, NIPS 2018。

### DPP 的扩展

**滑动窗口**：S 越大，其中相似物品越多、向量趋于线性相关，det 坍缩到 0，取对数趋于负无穷，算法失效。设置滑动窗口 W 代替 S：

```
argmax_{j∈R} θ·reward_j + (1−θ)·log det A_{W∪{j}}
```

**规则约束**：每轮先用规则排除 R 中不合规物品得到子集 R′，再求解：

```
argmax_{j∈R′} θ·reward_j + (1−θ)·log det A_{W∪{j}}
```

## 5. 本章小结

本篇记录推荐系统链路中的最后一环「重排」，本质是对推荐系统多样性的考察，多样性更能体现用户的个性化。

多样性通过物品相似度度量：可以用物品属性标签，也可以用物品向量表征。小红书笔记天生包含文字和图片，常用 CV（CNN）和 NLP（BERT）模型提取图文特征向量；因为图文相关性强，预训练用无需人工标注的 CLIP（图文匹配 + batch 内负样本）。

推荐系统希望曝光物品尽量两两不相似，所以粗排和精排后都有后处理。本篇记录了两种提升多样性的算法：

- **MMR**：来源于搜索排序。基本思想是从全集（未选中）中选择「兴趣分数 + 多样性（与已选集合的相似度惩罚）」加权分最高的物品放入已选集合
- **DPP**：经典机器学习方法。在 MMR 思想上用物品向量张成的超平行体体积替换成对相似度度量，实际用矩阵行列式衡量；Hulu 提出 Cholesky 分解的快速求解方法，是该论文的主要贡献

两种算法有一个通病：已选集合越来越大时，待选物品与集合的相似度趋近 1，算法失效。解决方案是滑动窗口（最近约 10 个物品）。滑动窗口也有现实合理性：离得远的物品可以相似、不影响体验，离得近的物品必须差异大。

实际应用中还需要规则约束（对笔记、广告、营销卡片等的重复出现做限制）：先用规则过滤一遍未选中集合，再用过滤后的集合参与多样性算法筛选。

## 复习速记

- 重排目标：从精排 pointwise 打分的 n 个候选中选 k 个，总分高 + 多样性强；粗排、精排后都有后处理
- 相似度度量：属性标签（类目/品牌/关键词加权和）、双塔物品向量（长尾问题、不好）、内容向量（CNN+BERT 拼接，CLIP 图文自监督预训练）
- MMR：`MR_i = θ·reward_i − (1−θ)·max_{j∈S} sim(i,j)`，贪心逐轮选 MR 最大
- 滑动窗口：S 太大 max sim ≈ 1 失效；用最近 W 个代替；离得远可相似、离得近要差异大
- 重排规则：连续出现限制、每 k 篇最多 1 篇运营推广、前 t 篇电商卡片限制；每轮先规则筛出 R′ 再选
- DPP：k 个向量张成超平行体，`det(VᵀV) = vol²`；正交 → 体积 1（多样性最好），线性相关 → 0
- DPP 目标：`θ·Σ reward + (1−θ)·log det A_S`；贪心添加物品 = 给 A_S 加一行一列，与已有物品相似会压垮行列式
- DPP 加速：暴力 O(n·k⁴) 级别太重（线上只有约 10ms）；Cholesky 分解增量更新行列式，降到约 O(n·k³)（Hulu）
- DPP 扩展：滑动窗口（det 坍缩）+ 规则约束（先筛 R′）
