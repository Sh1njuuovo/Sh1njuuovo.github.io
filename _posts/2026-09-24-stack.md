## 一句话概括

栈是一个只能从同一头进出的容器，最后一个进去的元素最先出来。它最擅长的场景是嵌套结构，也就是先把当前状态放一放，处理完里面再回来接着做。

## 什么时候用它

看到下面这些信号，先想想能不能用栈。

- 括号、标签、嵌套结构的匹配。20 题
- 需要记住上一步是什么，或者要沿着嵌套一层层退回来。394 题
- 要求某个操作 O(1)，但答案又依赖全部数据。155 题
- 求每个元素左右两边第一个比它大或者比它小的位置。739、84 题
- 递归能写，但想改成循环

## Python 基础

### 用 list 当栈

Python 没有单独的栈类型，list 就是最常用的栈。

```python
stack = []

stack.append(x)      # 入栈，放到栈顶
top = stack[-1]      # 看栈顶，栈本身不变
x = stack.pop()      # 出栈，弹出栈顶
if not stack:        # 判断是不是空栈
    ...
```

四个动作，`append` 入栈，`pop` 出栈，`stack[-1]` 看栈顶，`not stack` 判空。

`append` 和 `pop` 都是 O(1)，它们只动列表的末尾。

### 两个写法千万别用

`stack.pop(0)` 和 `stack.insert(0, x)` 都是 O(n)。列表底层是连续数组，动头部要把后面的元素整体挪一遍。

栈只动尾巴。如果确实需要从头部取，那用的是队列，应该用 `collections.deque`，它的 `popleft()` 才是 O(1)。

### 出栈之前一定要判空

空栈上 `pop` 或者读 `stack[-1]` 会抛 IndexError，这是写栈最常见的错误。带 while 的循环统一写成下面这个形式。

```python
while stack and 某个条件:
    top = stack.pop()
```

`while stack and ...` 这个写法值得背下来。Python 的 `and` 是短路的，左边为假就不会去读右边，所以永远不会在空栈上 pop。

### 栈和递归

递归调用用的就是系统自带的调用栈。所以递归能解决的问题，用显式写出来的栈也能解决。

区别在于，如果递归函数里有进去之前做一件事、回来之后再做一件事这种前后夹击的逻辑，改成栈就要额外保存状态。二叉树的中序遍历就是这种例子，递归三行，用栈要一路往左压到底。

## 单调栈

单调栈是栈里最重要的一类套路，739 和 84 都用它。

想法是让栈里的元素一直保持单调递增或者单调递减。做法是新元素入栈之前，先把所有破坏单调性的栈顶元素弹出去。

```python
stack = []
for i, x in enumerate(nums):
    while stack and 违反单调性:
        j = stack.pop()
        # 在这里结算 j 的答案
    stack.append(i)
```

三个要点。

- 栈里通常存下标。要算距离、要回头读原数组，都得靠下标
- 先想清楚栈的单调方向。求右边第一个更大的用递减栈，求右边第一个更小的用递增栈
- 结算写在弹出那一行。被弹出的元素，答案需要的信息刚好齐了

复杂度要记一句话，每个元素最多入栈一次、出栈一次，所以整个循环是 O(n)。外面套了 while 看着像两层循环，实际总共只走 2n 次。

### 哨兵技巧

在数组末尾加一个极小值，可以省掉循环结束后的收尾代码。84 题在末尾补一个 0，保证所有柱子最后都被弹出结算。

## Hot 100 五道题

### 20. 有效的括号

```python
def isValid(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []

    for ch in s:
        if ch in pairs:                 # ch 是右括号
            if not stack or stack[-1] != pairs[ch]:
                return False
            stack.pop()                 # 配对成功，弹出左括号
        else:                           # ch 是左括号
            stack.append(ch)

    return not stack
```

- 整道题只有三处会失败，右括号时栈空、右括号和栈顶类型不符、扫完栈里还有剩
- 字典的键放右括号，值放它要求的左括号，这样 `if ch in pairs` 一句就能判断当前是右括号
- `not stack or stack[-1] != pairs[ch]` 靠 or 的短路保护了空栈
- 易错：右括号时忘记判空，`s = "]"` 会抛 IndexError
- 易错：最后写成 `return True`，`"((("` 会被判成合法

### 155. 最小栈

```python
class MinStack:
    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, val):
        self.stack.append(val)
        if self.min_stack:
            self.min_stack.append(min(val, self.min_stack[-1]))
        else:
            self.min_stack.append(val)

    def pop(self):
        self.stack.pop()
        self.min_stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.min_stack[-1]
```

- 辅助栈的第 i 个位置存的是主栈前 i 个元素的最小值，所以它的栈顶永远是当前最小值
- `push` 时压的是 `min(val, self.min_stack[-1])`，压原值就错了
- `pop` 时两个栈必须一起弹，这样辅助栈的栈顶自动回到上一个最小值
- 为什么不能只用一个变量，因为最小值被弹走后就恢复不了。`push(-2), push(0), push(-3), pop()` 之后最小值应该是 -2，变量还停在 -3
- 易错：写成 `self.stack = self.min_stack = []`，两个名字指向同一个列表
- 易错：`push` 里忘记判断 `self.min_stack` 是不是空的

### 394. 字符串解码

```python
def decodeString(s):
    stack = []              # 存 (上一层的字符串, 这一层的重复次数)
    cur_str = ""
    cur_num = 0

    for ch in s:
        if ch.isdigit():
            cur_num = cur_num * 10 + int(ch)     # 处理多位数
        elif ch == '[':
            stack.append((cur_str, cur_num))     # 保存现场
            cur_str = ""
            cur_num = 0
        elif ch == ']':
            prev_str, num = stack.pop()          # 回到上一层
            cur_str = prev_str + cur_str * num
        else:
            cur_str += ch

    return cur_str
```

- 处理嵌套的三步节拍，遇到进入信号压栈并重置，处理里面，遇到结束信号弹栈并拼回去
- `[` 要压栈、清空 `cur_str`、清空 `cur_num`，三件事一起做
- `]` 的恢复公式是 `cur_str = prev_str + cur_str * num`，`prev_str` 不能漏
- `cur_num = cur_num * 10 + int(ch)` 是解析多位数字的通用写法，224、227 也要用
- 易错：忘记清零 `cur_num`，`3[a]2[bc]` 里的 2 会变成 32
- 易错：忘记清零 `cur_str`，外层的字符串会一直挂着

### 739. 每日温度

```python
def dailyTemperatures(temperatures):
    n = len(temperatures)
    answer = [0] * n
    stack = []              # 存下标，温度从栈底到栈顶递减

    for i, t in enumerate(temperatures):
        while stack and temperatures[stack[-1]] < t:
            j = stack.pop()
            answer[j] = i - j
        stack.append(i)

    return answer
```

- 栈里放的是还没找到更高温度的那些天，从栈底到栈顶温度递减
- 新来一天的温度比栈顶高，栈顶那天的答案就是今天，填 `i - j`
- `answer` 先初始化成 `[0] * n`，末尾剩下没弹出过的位置自动就是 0
- 易错：判断写成 `<=`。最小反例 `[73, 73]`，正确结果是 `[0, 0]`，用 `<=` 会得到 `[1, 0]`
- 易错：`while` 写成 `if`。`[75, 71, 69, 72]` 走到 72 时本该连弹 69 和 71 两个，用 `if` 只弹了一个，71 就永远等不到答案。结果是 `[0, 0, 1, 0]`，正确结果是 `[0, 2, 1, 0]`

### 84. 柱状图中最大的矩形

```python
def largestRectangleArea(heights):
    stack = []              # 存下标，高度从栈底到栈顶递增
    max_area = 0

    for i, h in enumerate(heights + [0]):        # 末尾补 0 当哨兵
        while stack and heights[stack[-1]] > h:
            j = stack.pop()
            height = heights[j]
            left = stack[-1] if stack else -1    # 左边第一个更矮的位置
            width = i - left - 1
            max_area = max(max_area, height * width)
        stack.append(i)

    return max_area
```

- 对每根柱子，把它的高度当矩形的高，宽度就是左边第一个更矮的位置到右边第一个更矮的位置之间
- 弹出 j 的时候两个边界一起齐了。右边界是当前下标 i，左边界是弹出后新的栈顶，栈空就用 -1
- 宽度公式是 `i - left - 1`，两端的矮柱子本身不能被覆盖，所以要再减掉一个 1
- 末尾补一个 0 当哨兵，保证栈里剩下的柱子最后都被弹出结算
- 为什么只需要枚举以某根柱子的高度为高，因为任何矩形往上顶到底，它的高一定等于覆盖范围内最矮的那根柱子
- 易错：宽度写成 `i - left`，少减 1
- 易错：忘记补哨兵，也没有在循环后清空栈，答案偏小

## 五题总表

| 题号 | 栈里存什么 | 单调方向 | 结算时机 | 时间 |
| --- | --- | --- | --- | --- |
| 20 有效括号 | 左括号 | 无所谓 | 右括号配对成功时弹出 | O(n) |
| 155 最小栈 | 辅助栈与主栈等长 | 无所谓 | 不需要结算 | 每个操作 O(1) |

`m` 是 394 解码后字符串的长度。

## 常见易错点

第一，空栈上 `pop` 或者读 `stack[-1]`。20、739、84 都有这个坑，统一写成 `while stack and ...` 或者 `not stack or ...`。

第二，用 `stack.pop(0)` 或者 `stack.insert(0, x)`。这两个都是 O(n)，栈只动尾巴。

第三，单调栈里存值不存下标。739 要算天数差，84 要算宽度，都得靠下标。

第四，`while` 写成 `if`。一次可能要连弹好几个元素，写成 if 只会弹一个，代码不报错但答案错。

第五，弹出条件的方向写反。739 用 `<`，84 用 `>`，方向反了栈的单调性就反了。

第六，循环结束后忘了处理栈里剩下的元素。739 用全 0 初始化绕开，84 用哨兵绕开。

第七，多个栈没有同步。155 里 `pop` 必须两个栈一起弹，只要长度错位，后面的最小值就全错。

## 共同规律

这五道题可以分成三类。

第一类是结构匹配，20 和 394。它们的共同点是都有明确的开闭信号，比如 `[` 和 `]`，或者左括号和右括号。处理方法是同一个节拍，进入时压栈保存现场，结束时弹栈恢复现场。

第二类是单调栈，739 和 84。它们的共同点是都在问左右两边第一个比它大或者比它小的元素。写之前先确定三件事，栈里存什么、栈朝哪个方向单调、什么时候结算。

判断信号也很清楚。

- 求右边第一个更大的，用递减栈。栈顶小，进来一个大的就把它弹掉
- 求右边第一个更小的，用递增栈。栈顶大，进来一个小的就把它弹掉

第三类是设计题，155 单独算。它的思路是空间换时间，把每一步的状态都存下来，取值的时候直接读。同样的想法后面还会见到，前缀和是把每一步的和存下来，前缀最值是每一步的最大值存下来。

最后一个共同的效率来源。栈的题目普遍是 O(n)，即使代码里出现了两层循环，也要意识到每个元素最多进出栈各一次。这是栈题在复杂度上说理的标准方式。

还有一句关于结算时机的话。单调栈的结算写在弹出那一刻，因为被弹出的元素，它的答案在那一刻刚好凑齐。找错了结算位置，逻辑就会绕。
