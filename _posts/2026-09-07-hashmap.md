## 一句话概括

用哈希把「判断存在 / 按值查找」从 O(n) 降到 O(1)，空间换时间。

## 适用信号

- 暴力做法要反复查找 / 两两比较，题目又要求 O(n)
- 需要记住「见过的值」或「值 → 下标 / 计数 / 分组」
- 需要把元素按归一化 key 归组

## Python 基础：dict / set 速查

dict 存「key → value」（相当于 HashMap），set 只存 key、用于判断存在与去重（相当于 HashSet）。两者底层都是哈希表，查找 / 插入平均 O(1)，代价是额外 O(n) 空间。

```python
# dict
d = {}
d["k"] = 1                  # 存 / 更新
d.get("k", 0)               # 查，不存在返回默认值 0
"k" in d                    # 判断 key 是否存在，O(1)
del d["k"]                  # 删除

# set
s = set()                   # 或 set(nums) 直接去重建 set
s.add(3)
3 in s                      # 判断是否存在，O(1)
len(s)                      # 去重后的大小
```

常用工具：

```python
from collections import defaultdict, Counter

dd = defaultdict(list)      # key 不存在时自动创建空 list，适合分组
dd = defaultdict(int)       # 默认 0，适合计数

Counter("hello")            # {'h':1, 'e':1, 'l':2, 'o':1}
```

key 的要求：

- key 必须是不可变类型：`int`、`str`、`tuple`、`frozenset` 可以；`list`、`dict`、`set` 不行（可变、不可哈希）
- 字符串拆字母排序后返回 list，当 key 前要拼回字符串或转 tuple：`"".join(sorted(s))`

## Hot 100 三道哈希题

### 1. 两数之和 —— 补数配对

```python
def two_sum(nums, target):
    seen = {}                      # 值 -> 下标
    for i, x in enumerate(nums):
        if target - x in seen:     # 之前的数里有我的搭档吗
            return [seen[target - x], i]
        seen[x] = i                # 先查再存
    return []
```

- map 存「值 → 下标」，每个 `x` 查 `target - x`
- 易错：必须先查再存，先全量存会和自己配对（如 `[3, 3]`、`target = 6`）

### 49. 字母异位词分组 —— 归一化分组

```python
from collections import defaultdict

def group_anagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        key = "".join(sorted(s))   # 异位词得到同一个 key
        groups[key].append(s)
    return list(groups.values())
```

- key 要让「同类同 key、异类不同 key」：排序后字符串，或 26 字母计数元组
- 易错：`sorted()` 返回 list，不可哈希，要 `join` 成字符串；单词很长时计数版 O(n·k) 更优

### 128. 最长连续序列 —— set + 起点剪枝

```python
def longest_consecutive(nums):
    num_set = set(nums)
    best = 0
    for x in num_set:
        if x - 1 in num_set:       # 有前驱，说明 x 有更早的起点
            continue
        length = 1
        while x + length in num_set:
            length += 1
        best = max(best, length)
    return best
```

- 只从「`x - 1` 不在 set」的起点向后数，每条连续链只扫描一次
- 易错：去掉起点判断会退化成 O(n²)

## 共同规律

暴力慢在反复查找 → 哈希把查找变 O(1) → 再用一个小技巧避免重复劳动：

- 1：先查再存，避免自己配对
- 49：key 归一化，同类一次归组
- 128：只从起点扩展，避免重复扫描整条链

## 复杂度

| 题号 | 时间 | 空间 |
| --- | --- | --- |
| 1 | O(n) | O(n) |
| 49 排序版 | O(n·k log k) | O(n·k) |
| 128 | O(n) | O(n) |
